# 武器动态占位与混装净空规划 V0.2

日期：2026-10-07。状态：**占位审计与候选设计约束，未改装配/升级规则**。适用于390×844、车头与车厢宽74 B的正俯视战斗。B是画面绘制单位，不是行驶距离单位。坐标以下均以对应车头/车厢的逻辑中心为原点，x向右、y向车尾。承接[显示包络V0.1](./武器装配显示包络规范V0.1.md)，但该文件只量了静态外形；从本版开始，任何武器的**最大工作包络**也必须算入占位。

> 2026-10-08 补记：本文件第2～3节记录的是**旧纵向往复规则的失败审计**。用户随后确认横向往复，浏览器原型已改为前后半长30 B不变、最远横向70→90 B。新规则在一级厢“1刀盘＋2尾排P”12时点试演有2 B理论实体净空；喷流、高级厢多刀盘和真机仍未验。当前状态见《武器升级部件与逻辑规则V0.1》与主线计划，不应继续把旧纵轨当现行实现。

## 1. 所有挂点统一使用的空间合同

每个实体挂点必须分别登记：承力根部、静态实体矩形、旋转/位移/开合的全时段扫掠包络、攻击或喷流特效包络、进入/退出动作，以及与车轮、车钩、相邻车辆和其他挂点的净空。判定按所有已开放升级态的**并集**进行，不能只测当前基础图或某一帧。实体活动部分与另一实体活动部分至少留2 B可见净空；特效可跨越空中，但不能掩盖别的设备工作识别，也不能用视觉分层掩饰实体穿模。车顶设备与侧挂设备若争用同一甲板/边梁连接面，同样视为占位冲突。

| 位置 | 当前中心/根部（B） | 必须预留的功能空间 | 当前状态 |
|---|---|---|---|
| 车头T四格 | 中心x=±10，y=-24/-5 | 每格实体最多18×20；还要为电弧输出方向及无人机舱门留工作空间；驾驶舱、铲刀和尾钩始终禁入 | 单格舱与紧凑电弧候选已画；混装和升级并集未审完 |
| 车头L/R侧挂 | 需从头部两侧边梁或T板引出真实承力点 | 电弧攻击端、未来侧武器的最大活动范围必须避开前铲、驾驶视线与车厢接头 | 现有紧凑电弧有候选图；没有独立的全升级态安全廊 |
| 车头P | 尚无独立核准的实体锚点 | 若允许装助推器，必须先画出不盖驾驶/铲刀/尾钩的P座并量喷流 | **未规划完成**；现有容量逻辑仍可能允许购入，不能视为物理通过 |
| 车厢T四格 | 中心x=±10，y=+13/+36 | 每格实体最多18×20，格心距横20/纵23；舱门开合不得越邻格或侧挂运动廊 | 单格舱静态尺寸已验；舱门运动包络未定义 |
| 车厢L/R侧挂 | 根部需实接x≈±18～27的边梁；需按前/中/后实际排位登记 | 刀盘外缘、转动以及任何可动支架都属于占位，不得只按轴心或静止支架计算 | 目前只验证一组刀盘的中排坐标；第二/第三组尚无安全排位，不能推定有位 |
| 车厢P前左/前右 | 助推中心x=±36，y=-5；根部x=±27 | 本体17×19；喷流另算，轮面/前车尾钩禁入 | 四助推单独试演可见；与切割轮不能假定兼容 |
| 车厢P后左/后右 | 助推中心x=±36，y=+62；根部x=±27 | 本体17×19、喷口向后；喷流要检相邻车厢 | 静态与加长刀盘仅有5 B纵向间隙；全程喷流未验 |

以上是**位置接口**，不是“各位置可以无限独立叠装”的承诺。现有容量4/6/10表示数值预算；一辆车能否合法摆下所有实体仍须由占位审计证明。升级不放大车头/车厢，也不能以更小的任意缩图掩盖不满足包络。

## 2. 切割轮×助推器：实际最大包络

当前每购入一件切割轮会绘出左右一对刀盘，单件容量成本2；每个助推器容量成本1。基础刀盘半径15 B，中心x=±40、y=+25；“加长支架”后半径22.5 B，中心x=±47.5、y=+25。因此每侧加长刀盘的实体扫掠为x=±25～70、y=+2.5～47.5。后排助推器本体y=+52.5～71.5，与之只隔5 B（各留2 B后剩1 B容差）；前排助推器y=-14.5～+4.5，已与加长刀盘纵向相交。两者x范围同样相交，不能靠左右错开解释为安全。

现有“联动刀盘”让**单件**刀盘中心沿y=+25±24 B前后往复；叠加已要求的“加长支架”，单侧刀盘纵向扫掠扩大至**-21.5～+71.5 B**，与后P本体的纵向重合达19 B，且压到前P位，也越出当前约94 B长的车厢有效轮廓。故即使基础静帧不碰，工作时仍冲突。原型现在仍可触发这项升级，不能把它报告为通过。

| 同厢组合 | 容量4一级厢 | 当前装配/运动结论 |
|---|---|---|
| 1切割轮＋1～2助推器 | 允许；助推器按当前数量落后排P位 | 不开“联动刀盘”时，含加长支架的静态净空为5 B；仍须用冲刺全程验证喷流及车轮。开启联动则FAIL。 |
| 2切割轮＋助推器 | 不允许，容量至少5 | 高级厢容量6/10会变成合法组合；现有重复刀盘/后排P占位未解决，不可因为一级厢没问题就宣称全等级安全。 |
| 3切割轮或更多 | 一级厢不允许；高级厢可允许 | 同侧至少三排直径45 B刀盘需约135 B，加净空超过94 B车厢；当前逐件画法不满足物理空间。需要重新设计真正可数的集成阵列或明确物理上限，不能叠在同一位置。 |
| 4助推器 | 一级厢允许 | 不与切割轮同厢；四P单独的静态包络可作为检查样板，整段喷流与前后车净空仍未通过。 |

## 3. 升级路径处理建议与实施门槛

采纳用户提出的方向作为**后续设计基准**：不再为切割轮设计需要侵入邻位的往复轨道类升级；强化优先作用于刀盘本体、齿刃材料、传动和工作反馈，并把最强形态限制在该位置预留的运动廊内。现有“联动刀盘”及其前后覆盖30→50数值尚在运行原型中，本轮**没有悄悄删卡或保留收益换个图标**；下轮应把这张卡的功能、描述、视觉和存档兼容一起替换，再做实际混装验证。不能在保留前后50判定的同时声称取消了扫掠空间：玩法作用范围和视觉反馈必须一致。

高级厢容量6/10引起的“多刀盘＋助推器”和“三刀盘”冲突是另一项独立问题；仅取消往复轨道无法解决。下一步先枚举各等级所有现行可购买组合，给每件设备分配实际T/L/R/P实体坐标和最大运动包络；失败组合须在**可见集成阵列、装备占位规则、升级路线**中择一重设计，再请用户确认涉及容量/购买规则的变更。选择前不得暗加隐藏限制或宣称满载可装。
