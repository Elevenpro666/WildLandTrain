| 信息/操作 | 战斗画面规则 |
|---|---|
| 出站冲刺里程 | 只在本段出站自动冲刺及其结束后短暂显示正向米数；关卡内手动冲刺完全不显示米数。 |
| 手动冲刺 | 右下角唯一操作按钮。充能条在按钮内部，充满后可点；冲刺中、Boss封锁和选卡期间显示对应状态，不能触发时禁用。没有独立充能文字行。 |
| 返回整备、暂停 | 两个测试按钮从战斗 UI 移除；战斗中的暂停详情面板也不再向玩家展示。内部暂停规则没有删除。 |
| 经验／废料掉落 | 使用青色菱形、金色六角形从敌人位置飞向列车；没有数字或文字总结。实际经验和废料仍按原规则入账。 |
| 到下一站距离 | 不在战斗 HUD 显示；Boss 出现时仍显示 Boss 耐久。 |
