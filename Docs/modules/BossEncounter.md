# Boss遭遇契约

2026-09-24，Game/Battle内部状态增量，开发代理负责。依据用户确认：Boss登场打断冲刺，整个Boss战禁止冲刺。此限制不扩展到普通精英。

目标：第三段900米后进入Boss而非直接结算；Boss击败且列车存活才胜利。非目标：正式Boss美术、正式平衡、波次重构和存档。测试Boss600耐久、12伤害/2秒，入场1.5秒；沿用原精英建议做测试夹具，不称正式数值。

Battle拥有Boss敌人及进入时间、击败状态；createBattle的options.boss布尔配置启用。进入时调用Sprint.interrupt()取消active，保留剩余距离与energy；Boss期间暂停Sprint.step，release在业务层拒绝，无新增冷却。snapshot输出boss、sprintLocked、sprintInterruptedAt和done。击败条件不依赖渲染；无独立计时器、异步、平台依赖，统一step暂停语义。Journey终段仍只接受done快照，Bootstrap只注入段配置。

入场表现：从右前侧逼近车头侧面并保持拦截，避开左上强化摘要；已有敌人不清空，停止新增普通敌人。Boss贴近车头侧面让切割、电弧及无人机都能作用；占位锁链表达拖住列车。入场期间Boss不攻击，入场结束后按2秒周期攻击；列车不获得额外无敌，已有普通敌人照常攻击。无敌盾立即解除，镜头从当时位置连续归中，背景速度连续减至常速。

UI：右上改Boss耐久，不显示0米等待；下方说明“Boss拦截 · 无法冲刺”，满能量也禁用。暂停与选卡仍冻结全部模拟。

验证：短路线夹具强制覆盖冲刺中/非冲刺满能量入场、重复释放拒绝、能量冻结、位置连续、暂停、死亡、击败后done；真实三段浏览器进入Boss并截取320/390画面。生命周期沿Battle释放，无新监听。性能预算/微信真机未验证。
