# EnemyArtView

## 感染者拖步接入
walkerView(e,time=0)为纯SVG描述，复用Battle模拟时间，每0.28秒换帧，id错相；击退固定帧。图集1774×887，两帧身体横向偏移不同，第二帧裁剪向左补偿约27源像素。显示视窗40×40，不改碰撞、速度、攻击；无新监听、状态、计时器或资源Owner。验收：两帧切换、只读、击退固定、暂停与完整旅程。贴车攻击动画尚未独立制作。性能/真机未验证。

## 简笔画飞行怪动画变更

目标：只接飞行怪两帧振翅，非目标为攻击规则、其他怪改造或新增动画系统。monster(e,t=0)增加模拟秒参数，Battle显式传s.t；旧调用缺省静止。两帧每0.16秒切换，按id错相，倒地击退固定帧并沿原角度旋转。使用同尺寸裁剪和共同身体锚点；不使用CSS动画/墙钟/额外循环。资源沿已有SVG图像加载，无新增Owner/监听/事件/异步。验收含时间换帧、同时间稳定、输入不变、两帧图片解码、小屏截图和真实暂停/恢复、完整旅程。测试标准文件未建立，按入口规范执行。

版本1，Presentation；负责人：开发代理。范围为当前四种敌人真实素材替换，不改怪池、坐标、碰撞、生命和伤害。

当前实现：仅游荡者素材成功，沿sprint-effects.mjs的monster(e)接入，尚未建立独立enemyArt函数；其他三类保持原表现。下述四种映射为待完成契约。普通怪32×26逻辑像素；击退沿原角度，速度线保留。生产批次部分被工具拒绝，记录到资产来源文档。

API：enemyArt(e)接收只读敌人快照并返回SVG字符串，逻辑坐标单位沿原表现；无状态、副作用、事件、监听、独立循环或异步任务。素材引用由既有浏览器渲染生命周期加载，模块不持有资源句柄。暂停/击退角度沿快照；生命条保留。定义未知时降级游荡者，飞行标记支持旧快照。依赖仅静态素材映射，无平台API。

验收：四种映射、只读输入、透明边界、320/390浏览器图像解码与截图、出站/Boss回归。动画暂沿位移与击退，非逐帧肢体动画。性能预算待M5设备测量，不声称微信验收。
