# 拖动合成与战斗反馈

状态：分步实施，2026-09-24。执行：开发代理。

## 本轮：拖动合成
- 目标：编组和周转中的同级车厢互拖，沿用合成确认与装备周转，不自动丢弃。
- 非目标：武器升阶模型、新货币、新输入系统。
- Adapters 的 mountDrag 拥有手势与拖影，松手提交 dropCart；Bootstrap 验证界面状态及车厢级别，复用 mergePair 确认；Station/Train 仍为合成权威。
- 输入：源 id、目标 to；自己、车头、异级、满级、空白位置均不合成。失败不修改物品。取消确认不改数据。
- 生命周期：沿用统一 pointer 监听，取消、失焦、后台、stop 清理拖影；无异步任务、无新事件总线和时钟。
- 验收：同级拖动出现容量及周转提示，确认后仅合成一次；无效拖动不弹详情不丢失；原装备拖动不受影响。手机浏览器检查，真机性能待 M5。

## 后续顺序

### 废料掉落（2026-09-25，测试经济）
- 测试每击杀1废料，配置lootConfig.scrapPerKill；未击杀的冲开/逃离不掉。经验规则不变。不是最终平衡。
- Battle持有本段scrapEarned，Bootstrap注入creditLoot到Economy.credit；每帧死亡实体移除后汇总一次回调，不由动画发奖。金币状六角图形表示现有废料，无新货币。
- 击杀立即入账，到站可花；测试返回保留已入账废料，重开全部重置。死亡不撤销已入账收益，但当前原型重开无局外保留。末帧奖励先入账再切场景。
- 快照输出scrapEarned与反馈中的scrap。暂停不推进，表现有界；无异步/新循环。验收击杀值、幂等重复step(done)、无回调模式兼容、暂停、进站余额、动画与回归。微信性能未验证。

### 经验反馈小步（2026-09-25）
- 本轮仅展示真实击杀的+1经验及飞向列车的粒子；经验仍在击杀时结算，动画不负责发奖、不推迟选卡。废料掉落下一轮。
- Battle唯一拥有lootFeedback记录（敌人id、坐标、模拟时间），最多64条、0.8秒清除，超限仅移除最旧表现、不影响收益；snapshot深拷贝。Presentation只读绘制，无新事件或时钟。
- 暂停/选卡冻结模拟与粒子，重开新实例清空，切场景不残留，无异步/新存档。击退但未击杀不产生经验。
- 验证：粒子对应击杀、经验未重复、暂停冻结、容量上限、320/390截图及升级流程回归。真机性能未验证。
1. 敌人掉落与吸收：经验与现有废料收益可见；金币图形不引入第二种货币。明确一次结算、暂停、末杀、到站和失败的归属，先配置后实现。
2. 波次与压力：显示当前敌群阶段及下一次威胁预告，配置预热、密集、缓冲；必须对应真实生成变化，不以标签冒充难度。保留时间遭遇与冲刺策略，不补发错过的经验；Boss 仍强制打断并禁止冲刺。
3. 连续实测三段，检查掉落收益、选卡频率、压力可读性与原冲刺手感。

武器拖动合成需先定义等级、伤害、容量及分支继承，单列后续，不把车厢规则暗套到武器。
