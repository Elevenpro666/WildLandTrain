# 真实车体展示增量
2026-09-25，Presentation，执行角色：开发代理。

目标：以同风格独立车头/车厢素材替换战斗占位车体，同步整备载体缩略图。车头以驾驶舱、动力结构及撞角区别于平整载装车厢，后部保留装备平台，装备独立。非目标：容量、车距、碰撞、战斗数值、等级外观全套制作。

API计划：trainBody(car,isHead)返回SVG绘制描述；stationBody(isHead)返回朝右缩略绘制描述。只读坐标，不修改状态。固定资源/源像素边界由展示模块管理，无反向Game依赖、事件、存档、异步任务、循环或私有句柄。SVG图像由现有浏览器生命周期管理；资源压缩/统一预加载和微信适配延续当前M4候选边界，M5复查。

验收：方向朝上/站内朝右；甲板电弧不遮车头；最大5载体不裁切；320/390战斗及入站、选择、拖动流程回归；实际图像decode成功。设备性能预算待定义，不以桌面浏览器代替真机。
