# 战斗试作契约

最新行程规则：到站由实际累计路程决定，测试路线975米，常速25米/秒、冲刺沿用100米/秒；取消30秒强制终止。每步按冲刺剩余距离拆分高速与常速时间，路程封顶。snapshot提供routeRemaining米，暂停不变；成功达到0由既有Bootstrap进入Arrival。975米用于接近原无手动冲刺的30秒体验，不是正式平衡值。冲刺HUD按最近释放时间及距离/速度计算结束时刻，保留2模拟秒、0.5秒淡出；下次释放恢复显示。测试需覆盖距离、跨速度边界、手动冲刺缩短到站时间及淡出暂停。

手动冲刺表现更新：Battle.snapshot增加sprintStarts成功释放时间数组的深拷贝，唯一Owner为Battle，退出随实例释放；仅成功release追加，暂停/无能量等拒绝不追加。30秒上限与8秒充能约束下最多4项。Presentation据最近时间驱动手动前冲（中央起步）、前置保持和归中，并连续叠加景物速度曲线。无新循环/平台依赖，生命周期仍由现有Battle控制。

## 冲刺增量契约

本轮增量：站内以静态外围怪群预示出站围堵，战斗初始化36只地面怪；冲刺碰到护罩范围的怪物进入击退状态，向两侧飞散，退出画面后移除，不算击杀、不发奖。Battle拥有击退速度/剩余时间及撞击反馈，沿用唯一step；Presentation绘制护罩、冲击弧、速度线、翻滚与短促震动，不增加计时器。击退期间不攻击、不被武器重复结算。验收包含围堵初始数量、实际击退位移、无敌免伤、特效退场、暂停冻结、手动冲刺复用。敌人上限仍40，撞击反馈只保存最近一次；参数仅供试作。性能规范尚缺，真机性能未验证。

目标：出站自动冲刺、逻辑距离结束、单条充能满后手动释放。非目标：正式品质成长、完整速度阶段、正式数值平衡。
Game 内部 sprint.mjs 由 Battle 唯一拥有，复用现有 step，无事件、异步任务或独立计时器。createSprint(quality,boosters) 输入品质1～3、已安装助推器数量；step(dt) 输入秒，release() 返回是否成功，snapshot() 返回独立数值快照。Battle.release 在暂停、死亡或结束时拒绝；重复释放因能量清空而拒绝。离开战斗丢弃实例，重新出站创建并自动冲刺，无存档。
测试配置：品质基础距离300/420/540逻辑米，每个已安装助推器加120米，速度100米/秒，非冲刺战斗中8秒充满。不与画布像素绑定；背景滚动仅为表现映射。助推器占1容量、20废料，为可替换的体验参数。品质按钮仅测试，不代表正式免费成长机制。
验收：满充不自动释放、无敌阻止扣血、重复释放拒绝、暂停不充能、不消耗距离、品质装备影响距离、返回站点保留装配。性能预算待定义；本轮浏览器验证不能代替微信真机验收。
