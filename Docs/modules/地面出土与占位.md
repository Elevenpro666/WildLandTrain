# 地面出土与占位

Owner为createBattle。ground-bodies提供纯groundProps(distance)及separateGround(enemies,distance)，仅由战斗步调用。展示借只读同配置，不持有权威位置。

普通地面波次敌人bornAt记录出场，1.3秒内emerging，随地面行驶距离偏移；结束后恢复既有移动速度，无瞬移追车。alive排除emerging，禁止地下受击/攻击。初始围堵、精英、Boss及飞行规则不变。

普通地面活体半径14，最多40常规波次实体，12轮分离；树根半径7，石块10/12。击飞、离场、死亡、飞行、Boss不参与分离。没有额外循环/监听/资源，暂停/停止沿Battle。位置归Battle，展示函数不修改。

验证ground-bodies纯规则与原波次/Boss/分支/远征回归PASS。是基础占位不是完整寻路；12轮不能证明所有任意密度绝无交叠，未验证真机性能。新增占位可能改变围攻节奏，平衡待整体验收，未暗改伤害数值。
