# 飞行怪同层占位

日期：2026-10-06。目标：避免飞行怪互相完全叠住，同时维持其越过地面物体的直观行为。非目标：3D高度物理、树石碰撞、飞行怪与地面蝎子互推、修改武器伤害或列车攻击距离。

职责：`src/game/air-bodies.mjs` 导出 `separateAir(enemies)`；只对存活、未击飞、未离场的 `fly` 敌人按24世界单位的同层占位直径做两遍确定性分离。由现有Battle步进在地面占位后调用；不持有状态、不产生事件、不管理资源，不建立第二个循环或计时。列表属于Battle，函数只更新其飞行怪位置。现有近身攻击仍由Battle按列车距离结算，飞行怪能从空中靠近列车攻击，但不参与树石／地面怪推挤。

验收：两只重合的飞行怪分开；地面怪与飞行怪重合不互推；击飞／死亡者不占位；完整战斗的命中、暂停、胜败与重开不回归。单测 `verify-air-bodies.mjs`、`verify-ground-bodies.mjs`，整段 `verify-contact-loop.mjs` 和 `verify-full-expedition.cjs`。视觉高度单独由 `approved-art.mjs` 的本体与地面投影表达，二者不改变碰撞坐标。

限制：所有飞行怪当前处于同一抽象高度层；未来若有不同高度或巨型空中单位，需要按层和体积配置重新设计，不能继续共用24单位。尚无微信真机性能数据。
