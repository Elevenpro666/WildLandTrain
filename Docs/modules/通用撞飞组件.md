# 通用撞飞组件

2026-10-06最新决定：用户澄清仅固定视口裂纹停用，放大的前景蝎子继续保留。`screen-impact-view.mjs`现在只渲染一只蝎子的固定视口腾空演出，不产生裂纹；演出期间抑制同一只蝎子的世界层重复绘制，其余蝎子撞飞、空翻、离地影和后甩保持启用。下文裂屏相关段落仅为历史方案，不代表当前运行效果。

2026-10-06出站后甩修正（历史记录）：原规则撞飞蝎子地面y仅每秒+130，而表现层又向屏幕上方抬升，导致它长期停在车头前。地面轨迹改为按1.1秒飞行年龄向列车后方推进760场景单位；离地影与身体分开。最初抬升系数为45%，后按用户要求增加至85%，该历史数值不再代表当前默认速度。撞飞目标在飞行时长结束时退出。未改伤害、击杀和奖励。

2026-10-05体积姿态：新增frames（可选可信SVG字符串数组，至少2帧）、variant整数0～5。按六组弧线/高度/散开距离/节奏配置播放帧，均匀缩放，不再把图片压成薄片；没有frames时显示原body。蝎子使用scorpion-roll-v1.png的背/侧/腹/另一侧4帧。最多2只近镜头策略仍由调用方决定。

2026-10-05：新增lane参数[-1,1]控制朝镜头散开方向，默认1；camera模式减小平面旋转，以纵向压缩/翻面表达翻身（没有腹面素材，非真实3D翻滚）。测试阶段出站6只，仅两只camera，其余side，选择策略仍在调用方。

Presentation纯函数组件，入口knockback-view.mjs。负责轨迹、缩放、旋转、离地影与淡出；不负责选中怪物、伤害、掉落和资源加载。

API：knockbackView({x,y,originX,age,duration,angle,mode,body,width,height})返回SVG片段。坐标/尺寸为场景单位，时间为秒，angle为角度；mode为camera或side。body为项目内部可信SVG片段，以原点为中心，不接受外部用户HTML。允许放入图集帧或独立图片，不关联怪物种类。默认30×36.5、1.1秒，保持现有蝎子效果。

由调用方提供主模拟时钟派生age及已加载素材；无状态、无监听、无异步、无新增循环与资源所有权，重复调用确定一致，结束返回空字符串。暂停沿用同一age。非法坐标、时间/尺寸/模式抛错。

验证：两种不同图形接入、两种轨迹、结束清理、非法输入、原蝎子集成回归；浏览器截图检查。微信性能未验证。后续其他兵种逐个接入，不声称已全部迁移。

## 出站长列与镜头撞击候选（2026-10-06）

目标：默认500 SU/s出站的普通蝎群纵向覆盖约2秒行程，横纵位置有受控错位而非整齐配对；撞飞空中高度比上一版更大；一只被选中的蝎子短暂翻向镜头并出现固定屏幕坐标的裂纹反馈。非目标：修改列车速度／品质距离／怪物伤害／掉落，或真的修改设备屏幕。验收：品质一1.92秒冲刺内绝大多数首群被撞飞，较远个体在末段才撞上；320／390宽画面能看清腾空、撞击、裂纹及消失，HUD始终可读；三段远征不退化。

职责：`departurePositions`只生成确定性的生物式错位位置；`Battle`只处理碰撞与地面后甩；`knockbackView`只处理离地高度；`screenImpactView`只读已有撞飞快照，在根SVG视口绘制无交互、短时的前景怪与裂纹。唯一时钟仍为Battle主模拟时间，暂停时冻结；没有监听、异步、独立循环或持久化。出站焦点只选一只示范个体，不把每只撞飞怪都放大到屏幕上。候选效果可通过回退位置、抬升系数和视口叠层恢复旧版。

用户观察到持续震屏使动作难以看清。根因是旧表现层每当`impact>0`就以约15Hz、左右3 SU摆动整个战场；26只首群连续撞击使该状态反复刷新。现改为初始无敌冲刺期间不抖整张战场，保留个体翻滚与裂屏；后续非开场单次碰撞的左右位移上限0.7 SU。仅修改Presentation，不改权威撞飞、伤害或时钟。验收用连续碰撞帧的`data-battle-shake`位移、两宽裂屏截图和完整远征回归。
