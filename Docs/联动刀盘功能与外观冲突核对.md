# 联动刀盘功能与外观冲突核对

日期：2026-10-06。状态：用户已选方案二；已同步规则文案与表现。

## 核对结果

《首批武器分支与战力验证方案》与卡片文案写“增加前后错开的刀盘／增加刀盘，沿轨覆盖前后30→50”。规则实际只把每件切割轮的沿轨半长从30改为50，伤害与间隔不变。表现对一件切割轮是2片→4片；但当前起手同车厢已有两件，表现却是4片→4片，只把前后间距44→60并加传动梁。因此“双件情况下增加刀盘”并未兑现。现有 `verify-saw-family` 只验证结构元素/间距，没有验证新增刀盘数量，之前的静帧候选通过不能等同于功能表达通过。

|---|---:|---:|---|

## 决定与落地

用户确认“刀盘太多，空间不够表达”，采用现有刀盘沿导轨前后扫切的方向。联动不增加刀盘数量：一件始终两片，两件始终四片。规则沿轨半长仍为30→50，伤害、间隔与同敌不重复结算均不改。表现为外侧导轨加现有刀盘往复工作；两件同装的盘距在44～60之间随时间变化。卡片和首测文档不再承诺增加刀盘。高级银灰齿刃图不变。实战动态可读性仍需用户在游戏中验证，不因静帧通过而宣称定稿。

## 曾讨论的两个互斥处理方向

1. **保留“增加刀盘”承诺**：每件切割轮在联动后都增加实际可见工作刀盘。两件同装时必须在小屏验证新增刀盘不互盖、支架和命中范围一致；不应为了数量堆出一团齿圈。具体增加几片及排布需设计、实现与实战检验。
2. **以现有规则和清晰画面为准（建议）**：定义联动为现有刀盘通过传动结构前后展开、沿轨覆盖30→50；改卡片和设计文案，不再承诺数量增加。保持四片、传动梁及前后工作位，并验证玩家能看出“覆盖变长”而非误认为“买了第二件”。

原冲突记录保留用于追溯。方案一已放弃，不再继续堆刀盘。
