# 无人机扩编实战试演 V0.1

日期：2026-10-08  
状态：已接入真实战斗试演；玩家目测待确认。

## 目标

让玩家在真实战斗中直接判断`droneCount`强化后，视觉上是否明确表达“同一无人机舱多出一架无人机”，并能看到两架无人机实际分开巡航、索敌和攻击。

## 范围

- 新增入口参数：`weaponTrial=droneCount`。
- 仅试演局外预置一层现有`droneCount`强化；无人机舱与其他装备使用当前开局组合。
- 使用既有无人机实体生成、巡航和索敌逻辑，不制作数字替代，不新增无人机舱，也不改变正常升级流程。
- 普通游戏入口、敌人规则、伤害、速度、容量与经济均不变。

## 使用与验证

- 可操作页面：`http://127.0.0.1:4191/station-prototype/?art=approved&platformArt=carV1&weaponTrial=droneCount&v=drone-count-trial1`
- 页面已出站进入战斗；可以观察同一舱的两架无人机是否容易分辨，是否各自离舱活动，以及是否形成独立目标分工。
- Playwright状态快照：出站后无人机实体数为2，均归属同一无人机舱；快速推进至敌人出现后，两架分配了不同目标。基础页面无新错误。
- 短时截图位于敌群尚未进入索敌阶段，只用于定位状态，不作为视觉验收。微信真机未验。

## 验收边界与下一步

玩家目测待确认：两架无人机在手机竖屏实际比例下是否一眼可数、轨迹是否分离、独立索敌是否读得出。未确认前不称美术通过。若辨识不足，只调整无人机本体/巡航表现，不改变扩编数值与攻击规则；之后继续A06剩余武器升级资源，不以该单项代替整族验收。
