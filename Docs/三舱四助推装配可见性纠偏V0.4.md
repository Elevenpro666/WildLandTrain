# 三舱四助推装配可见性纠偏 V0.4

日期：2026-10-07。用户提供的两张截图说明上一轮“节点数量正确”不等于视觉成立：三座舱连成一座大舱，四件助推器在车外漂浮。仅修候选装配表现；不改容量、速度、战斗效果及默认美术。

## 本轮修正

- 三级厢三座无人机舱继续按三块T格分配，但每座改为 15 B 宽贴图与 18×20 B 独立暗色底座，横向两座之间留 2 B 明缝，前后排之间留 3 B 明缝。保留每座独立舱口，不以一张跨三格大图或数量数字代替。
- 四件侧助推器中心由车体中线 `±45 B` 收回到 `±42 B`，使主体内缘与74 B车体轮廓重叠；每件增加从 `±32 B` 车体边梁向外的实心承力板、两条可见加强筋与内侧铆点。原素材与候选蓝灰素材均保留，候选一喷口配一条喷流，不再把旧双喷口特效套到单喷口图。
- 挂载验证页增加 `sprintMoment=1` 工作态取景入口；普通取景和实战逻辑不变。
