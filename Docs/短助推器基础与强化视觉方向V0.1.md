# 短助推器基础与强化视觉方向 V0.1

日期：2026-10-08。适用：390×844 正俯视、尾排单孔15×12 B、车距85 B。

## 已认可的基础态

用户认可 `美术设计/M21推进装置/尾排短助推器正俯视候选V3.png` 作为**基础外观方向**：短宽涡轮机组、蓝灰车体同系护甲、车尾短喷气口、四件各占一孔，安装梁贴合车体。不表示默认游戏资源已经替换，也不表示联动刀盘/高阶混装净空通过。

## 强化态只改变功能结构

- 保留同一15×12 B孔位、四个独立可见件、90°正俯视、蓝灰装甲和安装梁，不加长机身、不增加外置底板或装饰层。
- 涡轮：让转子及强化环成为更大的主形，优先在实际游戏尺寸读出“推力核心增强”，而非仅增加细碎叶片数。
- 喷气口：单出口变为同一机组内的双通道/扩口结构；工作态对应更明确的短距双股喷流，不穿过后车，也不凭空多出第二台设备。
- 当前游戏规则为每装一件助推器增加120**玩法米**初始冲刺距离（1玩法米=3.2场景单位；此前“120场景单位”系单位笔误），**尚无单件强化等级或强化收益**。强化图只用于视觉试演，不把双喷口暗示为未经定义的伤害或速度加成；正式接入需先确定对应能力。

## 第一张强化候选与验收

以内置生成工具对基础V3作约束编辑，生成 `美术设计/M21推进装置/尾排短助推器强化涡轮双喷口候选V1.png`：放大转子与金属环、尾部双通道，保留护甲和尺寸。`mount-fit-review.html` 仅在 `boostArt=enhanced` 显示它，并在相同包络内补可见转子亮环与双出口亮线。实际390×844冲刺画面已目检、状态中仍为四件且网页无报错；但与基础版的**即时视觉级差仍偏弱，未通过强化可辨验收**。不能当作升级定稿，也不能因此更改现有冲刺数值。下一轮若继续，应在不扩大占位的前提下优先调整转子/出口的明暗主形和工作态节奏，而非再堆纹理。
