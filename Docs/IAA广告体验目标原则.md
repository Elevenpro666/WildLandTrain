# IAA广告体验目标原则

状态：产品方向记录，未实施。依据：用户本轮明确要求。

## 核心要求（已确认）

后续用户补充：商品结合列车与装备等级保持明确成长吸引力，形成“都想要但预算有限”的策略取舍；系统解释收益和代价，不替玩家判断选择。不能因装不下或满编阻止广告获取或隐藏商品。获取和装载分别处理；内容开放限制必须展示所需章节或等级及开放后的能力。教学要解释武器能力、装载空间与编组数量分别如何变强，不能只教点击。最终上限于2026-09-29确定为车头加五节车厢，具体开放节点待定，不据此恢复内部容量广告解锁。

每一个广告点必须能用简短文字说清楚：增强了哪一种具体体验，或降低了哪一种具体损失。广告收入不是面向玩家的价值说明；“给奖励”“加资源”不足以单独成立。

广告应结合玩家当前状态提供可理解的收益，例如推进现有装备的高阶合成、升级车厢，或在死亡后保留本局构筑继续挑战。不能通过人为制造损失、削减基础收益或增加重复门槛来证明广告必要。

## 候选方向

### 共同决策要求（用户补充确认）

升级机会只是候选方向之一，不是商店唯一价值。广告选项必须与免费选项及其他合理选项放在同一决策情境中，让玩家比较收益、成本和对当前构筑的作用后自行选择，不能只给一个看广告的必选项。

- 免费选项应真实可用、有实际价值，不能只是隐藏的关闭按钮或明显无效的陪衬。消耗局内废料的购买属于非广告选项，但不冒充免费领取。
- 选项可以分别解决当前火力、控制、生存、后续升级等不同目标；广告升级不应在所有情况下都全面优于其他选项。
- 同时说明各选项的效果、适用装备、容量影响以及代价，明确标识免费、废料购买、观看广告，不预选广告。
- 同场比较不等于所有场景强行三选一；互斥选择还是可以组合购买，需按具体场景另定，不在本原则新增次数门槛。
- 战败保留清楚的正常结算选择，说明已获收益与复活保留内容，不暗示不看广告就没收正常奖励；本原则不意味着新增免费复活。

### 前置教学与引导（用户补充确认）

先教会基础构筑与取舍，再介绍广告作为额外选择，不让观看广告成为教学通关条件。

建议引导顺序：用免费内容认识装备作用 → 正常装配并在战斗中看到效果 → 理解容量与升级取舍 → 在后续合适节点比较免费、正常购买和广告候选。具体教学关与出现节点待设计。

首次广告引导须说明“为什么这个选项对当前列车有用”，并允许直接选其他选项；之后展示所选结果，让玩家建立行为、反馈与收益的一致认知。不得用强制手指、无法关闭的遮罩或必须播放广告才能继续的流程完成教学。

### 候选点位

|场景|目标体验／减少的损失|候选奖励|展示要求|
|---|---|---|---|
|站点商店，已有可升级装备|更早体验当前流派的高阶能力|匹配现有装备的合成材料、同类模块或定向升级道具|指出目标装备、用途与升级后的变化；未能立即升级时，不承诺立即升级|
|站点商店，已有可合成车厢|推进扩建或容量升级目标|匹配当前车厢等级的合成所需物品或升级机会|明确合成前后容量、车厢数和装备处理，不承诺总容量必然增加|
|战败|减少本局构筑与挑战进度中断的损失|自愿观看广告后复活续战|明确恢复状态、继续位置和次数限制；具体规则待定|

上述是优先探索的产品方向，不代表已确定材料体系、直接升阶或万能道具机制。武器模块合成规则尚待确认，不能先围绕未定规则投放广告道具。

## 设计边界

- 广告道具优先服务现有升级规则，不额外增加广告专属货币、复杂兑换或隐藏配方。
- 保留正常游玩的获取与成长路径；广告提供额外机会或减少损失，不垄断核心能力。
- 结合当前装备生成推荐，但不是无限保证最优解；出现条件、频率和奖励强度后续测试。
- 广告兑换与合成操作分开表达：领取物品不等于自动执行合成、消耗原装备或丢弃装备。
- 车厢合成仍可能减少总容量；不得自动丢弃溢出装备，仍由玩家在临时周转区取舍。
- 不恢复永久容量广告解锁、不提供第六节车厢，不改变到站免费满修。
- 复活不等于到站维修；不扣回玩家已获得的正常结算来诱导复活。
- 广告不可用或用户放弃时，正常流程仍可继续；战败可正常结算，商店仍可正常操作。

## 广告点立项检查

每个点位先回答：

1. 玩家当前在追求什么，或刚失去了什么？
2. 奖励具体改变哪个装备、能力或进度？
3. 玩家何时能感受到变化，是否与文案一致？
4. 不看广告的正常路径是什么？
5. 是否绕过了容量取舍、合成确认或其它既定核心规则？

验证不只看观看率，还应观察领取后的使用率、目标升级完成情况、升级后下一战斗段的体验，以及拒绝广告后的正常流程。不能用观看率高单独证明广告体验合理。

## 后续待定
