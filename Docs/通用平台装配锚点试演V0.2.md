# 通用平台装配锚点试演 V0.2

日期：2026-10-07。承接 [V0.1](./通用平台装配锚点试演V0.1.md)。用户判定 V0.1 四电弧不像武器、三舱不能靠跨三格表达、助推器挡轮且过挤，V0.1 仅留历史对照。本轮仍只作用 `platformArt=carV1&mountTrial=fit2` 的候选画面，默认和玩法容量未改。

## 纠偏与实际结果

| 项目 | 新候选 | 390×844检查 |
|---|---|---|
| 四电弧 | 从零生成 `美术设计/M18电弧挂载验证/电弧单板叉口发射器原创候选V1.png`，不以原电弧图为编辑目标。每块T分别有装甲根座、青色能源核、短铜传导段及朝左右车侧的双叉攻击端；仅在发射口加短亮线待机反馈。单件显示宽26 B。 | 四件和发射方向可辨，横杆消失；但攻击端在运动/微信真机上的瞬读性仍需玩家审核。原生成图的细纹理在26 B几乎消失，不能把大图细节当作游戏验收。 |
| 三无人机舱 | 从零生成 `美术设计/M18电弧挂载验证/无人机单格独立舱原创候选V1.png`，单件一个开口、一盏状态灯；三件分别占 T-前左、前右、后左，宽21 B。 | 三座有独立轮廓和舱口，未跨格合并或用数字代替；舱门开合动作未重验。 |
| 四助推器 | 仍用现有助推器本体，改变的是装配而非图生图：第二车厢左右边梁各两座，纵向 `y=-10/+36 B`，外侧 `x=±47/±57 B`；两螺栓座和短承力梁接边梁，喷口向后。 | 静帧四件分为前后两排，未盖住车轮；前后喷流与相邻车厢的动态净空**未验证**。没有把旧助推器图说成新素材。 |

源图均为1254×1254 RGBA，透明角 alpha=0、主体 alpha>0；图像生成方式为内置 ImageGen 文生图，**未输入旧素材作参考或编辑**。新电弧提示词要点：90°正俯视、单格近方形底座、可见能源核、短铜传导段、朝右双叉发射口、蓝灰旧化、透明单件、禁横杆/侧视/外部闪电。新舱提示词要点：90°正俯视、单格独立舱、明显深色舱口与双门、青色状态灯、透明单件、禁数字/多舱/侧视。左右发射口由运行镜像处理。

## 验证与边界

- PASS：候选与默认六组挂载数量/容量/图片解码/页面错误检查；候选在标准游戏网页客户端短时推进与状态读取；默认320/390三段胜负和重开回归。`station-prototype/output/mount-fit-*-platform-fit2-390.png` 为候选截图。
- 视觉局部PASS：390截图中三舱确为三座，四电弧发射方向较V0.1清楚，四助推器主体未遮车轮。
- 未验证：玩家对四电弧“武器”的瞬时理解、三舱开合、四助推器冲刺喷流净空、微信真机，以及候选电弧的升级等级结构。新图并未替换默认运行资源。
