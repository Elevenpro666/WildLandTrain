# M4分支接入实测

2026-09-24。本机Node24、浏览器320/390宽；固定种子与旧起手夹具，无站点额外购入。不是胜率、真实玩家体验或微信性能结论。

## 已接入

- 十二张专属卡：每类型两条两级短链，单卡一次；只有已安装类型参与候选，高阶要求对应方向卡。
- 有效专属不足三张补一张供能，仍不足显示实际数量，不复制卡。供能按1+0.1×层数乘在专属变化之后，不改变冲刺。新增firstSupplyLevel记录首次选择等级。
- 电弧逐跳最近不同目标、双脉冲延迟0.15秒且失效目标取消；无人机每舱1/2架真实移动、25U接敌，巡防分散与集中策略；切割轮只攻击车侧地面区域。
- 经验需求5/8/12/16/20/24，后续24；成长跨站保留，HUD按类型汇总，避免十二行占满战场。
- 普通怪同步首测口径：地面24耐久、每1.5秒4伤害，飞行32耐久、每2秒5伤害。仍使用旧出生时间与移动测试夹具，不是阶段敌情已完成。冲刺速度、距离、充能及镜头未改，起手经济未改。

## 下一项需明确的关卡口径

现有刷怪按时间，冲刺缩短停留时间，因此本样本可少6次升级。这是实测差异，不直接判断错误。接入阶段敌情前，应确定主要敌群按里程触发（更快推进同一组遭遇）还是继续按时间触发（快走遇敌更少）。按里程不等于自动经验补偿，冲开的怪目前不算击杀；若更改其奖励另须单列。
