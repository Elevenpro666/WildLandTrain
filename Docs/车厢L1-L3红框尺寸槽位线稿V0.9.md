# 车厢 L1—L3 红框尺寸槽位线稿 V0.9

状态更新（2026-10-21）：用户已确认本线稿中的车厢/单槽尺寸作为当前规划基线。统一规则见[武器统一接口与五系尺寸规范 V1.0](./武器统一接口与五系尺寸规范V1.0.md)。

## 本轮目标

按用户提供的红框宽高作为单个武器接口的目标尺寸，把接口排布在现版车厢托板内。红框在截图中的位置不沿用；根据托板有效空间重新对齐和留边。只新增概念线稿与尺寸依据，不修改运行时车厢贴图、碰撞、相机或装配规则。

## 尺寸依据

- 车体可视宽沿用现版：70 B；当前长度约93.68 B，线稿旧基准约94 B。
- 用户截图红框约68×68屏幕像素；按车体显示宽约242像素对应70 B比例估算，接口目标包络约19.7 B见方，本线稿取整为20×20 B。
- 车厢托板原有四块装配板约15×18 B。红框尺寸代表武器接口/装备包络，而不是把原托板贴图尺寸直接改成20×20 B。
- 为在70 B宽车体内对称排列两列20 B方槽，横向中心设为±12 B，中心距24 B，槽间净距4 B；车体内缘约±27 B，槽外缘至内缘各留5 B。
- 纵向中心距沿用23 B，20 B槽之间留3 B。L2/L3按阵列两端各留10 B确定长度；L1的阵列需要61 B，短于70 B宽度，因此将L1长度下限定为70 B并居中排槽。10 B端距是候选值，不是正式车体规范。

## 已确认尺寸

| 等级 | 槽位排列 | 槽组纵向包络 | 车体尺寸 | 相对当前约94 B基准 |
|---|---:|---:|---:|---:|
| L1 | 2列×2排 / 4槽 | 20 + 23 = 43 B | 70×70 B | 比现版约94 B短24 B |
| L2 | 2列×3排 / 6槽 | 20 + 23×2 = 66 B | 70×86 B | 比L1长16 B |
| L3 | 2列×4排 / 8槽 | 20 + 23×3 = 89 B | 70×109 B | 比L2长23 B |

校核说明：横向槽中心距24 B、槽宽20 B，净距4 B；纵向中心距23 B、槽长20 B，净距3 B。阵列纵向包络43/66/89 B；L2/L3首末槽外缘至车体端部各留10 B，故长度86/109 B。L1按槽阵列加两端10 B需63 B，但采用70 B车长下限并居中（两端各13.5 B）。实际托板边梁、车钩和轮组端部结构还需正式车体美术确认。

相较此前约94 B的L1基准，L1候选每节减少24 B；4节L1的纵向长度合计减少96 B。该几何差值不直接等于屏幕像素或可视体验结论，仍需结合车头、车厢连接件、HUD与镜头评估。

## 结构表达

- 所有武器接口只在T面甲板，取消车壁武器挂点。
- 车宽70 B不变；装配包络改为20×20 B，横纵中心距24×23 B；L2/L3各增加一排。
- 轮组保持车体外侧，按每节车长约25%/75%布置；不得进入T面槽位。
- 该图不代表所有武器静态外形或攻击/运动包络均已通过验证。
