# 武器职能分类框架 V0.1

日期：2026-10-15。状态：分类规则草案，先于具体新武器造型与数值。依据用户最新方向：武器分攻击与防御；攻击按控制、伤害、持续伤害、范围伤害等战斗职能拆分；防御类以近身防护/拒止为目标，但辐射本身不产生拒止。

## 1. 分类原则：职能、效果和载体分层

武器升级结构已由[武器体系重梳理 V0.1](./武器体系重梳理V0.1.md)扩展为“基础家族/本体 → 升级部件及前置 → 终端构型/策略分支”。此结构只参考用户提供的外部技能表组织方式，不导入其数值、强度排名或每局抽取机制。

不要把“力场、炮、无人机、电弧、范围伤害”放在同一层级。它们分别可能是战斗大类、装置载体或攻击形态。每件装备按以下三个维度记录：

1. **战斗大类**：攻击 / 防御。
2. **主职能与副效果**：选一个主职能，副效果只用标签记录；标签可以交叉，不额外造一个重复武器家族。
3. **实现/视觉载体**：接触机构、投射体、光束/电弧、无人机、力场/辐射场等。载体回答“它长什么样、怎么工作”，职能回答“它对战斗状态做什么”。

所以“范围”本身是覆盖形状，不是与“持续伤害”互斥的职业：一件设备可以是“范围主职能＋持续伤害副效果”；也可以是“直接伤害主职能＋穿透/连锁标签”。

## 2. 一级大类与可能职能

| 一级类别 | 职能类型 | 结果定义 | 设计边界 |
|---|---|---|---|
| 防御 | 近身拒止 | 怪物进入车体周边防线时被推离、弹开或无法穿过边界，明确减少近身接触 | 力场/机械屏障等独立结构可承担；辐射不能单独拒止，边界触发与排斥方向需可见 |
| 防御 | 接触削弱 | 怪物靠近后被减速、短暂停顿或失衡，为列车争取距离 | 这是拒止的软控制形态；不能与完全阻挡同时假设，命中反馈须说明敌人为什么停下/后退。辐射只有在规则确实造成这些状态变化时才能标记为该职能 |
| 防御 | 损伤缓冲 | 护盾或装甲能吸收/降低列车受到的攻击，但未必阻止敌人接近 | 与“拒止”分开统计；只有确实影响受伤结果时才叫防护，外观不能暗示绝对墙体而玩法只有减伤 |
| 攻击 | 直接伤害 | 命中时立即扣除目标耐久，可进一步标注单体、直线穿透、弹跳/传导或追踪 | 这些是命中拓扑标签，不要仅凭同一伤害属性拆成多个系列 |
| 攻击 | 控制 | 改变目标的移动或攻击状态：减速、冻结、眩晕、击退、聚拢/偏转 | 若造成直接伤害，记录为副效果；控制强度要与画面中的停顿、位移或状态变化一致 |
| 攻击 | 持续伤害 | 目标在一段时间内或离开攻击源后继续掉耐久，例如燃烧/腐蚀/残留电荷 | 必须与“持续攻击频率”区分：刀盘反复命中不自动等于异常状态DoT；离开攻击源后仍造成伤害才算持续状态 |
| 攻击 | 范围伤害 | 一次覆盖多个目标，或在区域内多次命中 | 范围是空间覆盖维度；可附加直接爆发、持续伤害或控制，不另视为互斥状态 |

## 3. 防御表现专项边界

- **力场/实体屏障**可承担近身拒止：表现清楚的空间边界和受力结果，敌人触界后退、弹开或无法穿过。只有真实改变敌人接近结果，才算拒止。
- **辐射不具备拒止能力**：不能仅凭波纹、光环或干扰视觉让怪物被推开、停在边界外，也不把辐射单独列为拒止防御。
- **允许复合：拒止场＋辐射持续伤害**。独立的力场/实体结构负责阻止怪物近身；辐射可在其作用区内对近距离目标造成持续的穿透伤害。两者是同一装备上的不同效果，必须分别有规则与可见反馈：触界排斥表现拒止，命中/累积表现持续伤害。不得把伤害动画画成推力，也不得让“穿透”被误解为辐射突破力场后伤到列车。
- **护盾/缓冲层**若只吸收伤害，应明确其保护对象、受击反馈和耗尽状态；它和拒止场不是同一装备功能。未来若合并，需在一次命中中同时验证阻挡与减伤规则，不同时重复计算。
- 防御装备的工作区也是动态包络：力场半径、脉冲击退位移或护盾覆盖区均需单独登记。不得用攻击射程代替防御活动空间；与邻车/武器冲突未审查前不定装载位。

## 4. 现役武器按新框架归类

| 当前家族 | 战斗大类/主职能 | 副效果或载体标签 | 说明 |
|---|---|---|---|
| 切割轮 | 攻击 / 直接伤害 | 接触、横向扫掠、局部覆盖 | 反复接触命中是攻击节奏，不直接归为状态持续伤害 |
| 电弧 | 攻击 / 直接伤害 | 目标间传导、群体覆盖；控制效果只有逻辑/表现确实存在时才登记 | 多级传导是攻击路径，不等于多个发射器或一片持续电场 |
| 无人机舱 | 攻击载体，不是独立职能 | 自主移动/索敌；其主职能由机载实际攻击决定 | 现有电极攻击记为直接伤害；机体数量和分散索敌属于载体/目标策略 |
| 车头冲刺 | 车辆能力，不属于攻击或防御装备分类 | 出站冲出/路途中冲刺；距离只由车头品质决定 | 助推器不再作为装备类别，不能进入武器目录或装备数量统计 |

目前只有前三项对应现役可玩武器。**镭射武器已有按单个T面接口筛选出的候选设计；拒止＋辐射地雷已有概念候选，现统一改按T面接口重制，但运行包络仍未验证；两者均未批准为最终资产。**其他攻击职能尚无具体新武器定案。此表不改变现有伤害、控制或装配逻辑。

## 5. 具体武器立项前的筛选卡

每个候选先填写以下内容，缺任一项不画生产图、不进商店：

- 大类：攻击或防御；主职能：只能选一个；副效果：最多两个明确标签。
- 目标问题：它解决哪种敌情/列车风险，现有切割轮、电弧、无人机为何不能替代。
- 玩家可见因果：装置动作 → 命中/触发 → 敌人或列车状态改变；正俯视小屏下能否立即读懂。
- 载体候选：车体接口、供能/承力关系、静态尺寸、最大攻击/拒止包络；尺寸与装载位未验前不决定格数。
- 升级差异：改变哪个真实部件和哪项真实效果；升级本体与攻击/防御反馈同步，不把数量、范围、异常状态混为一个数值词条。
- 排重：主职能、攻击拓扑、目标群体和画面形态至少有一项与现役家族形成清楚差异；若只是同一职能换颜色/名字，合并为现有家族升级路线。

## 6. 本轮结论与后续

镭射武器现按T单槽≤18×18 B预算形成候选，但只通过静态尺寸筛选，未证明完整光束/混装矩阵通过，也未批准最终制作。拒止＋辐射地雷获得用户方向认可，现要求用统一T面接口重制；硬件锚点、尺寸、容量和全车作用范围仍需实装验证。破片投射、工业场控继续待筛；不为解决空间问题扩展未确认挂点。辐射不能拒止，地雷承担近距离持续伤害。
