# 荒野列车：共同远征成长规则

版本：0.1｜状态：设计提案，未实施

依据：《双市场产品结构方案》、PRD最新修订。用户同意继续细化不等于批准所有新增规则；本文件不自动覆盖PRD及原型。已确认约束与本轮建议分别标注。

## 1. 目标与边界

玩家一句话理解：一路打怪强化，到站换装扩车；整趟远征保留构筑，结束后带回研发成果。

本轮只规定成长对象、获得途径、保留范围和结算边界。不确定伤害、经验曲线、价格、站数、局长、广告次数，不增加新养成入口，不修改代码。

已确认：最多车头加五节车厢（2026-09-29 用户调整）；车头有容量但不参与车厢合成；当局购车，同级车厢合成提高单节容量但不必容纳原来全部装备；站内临时周转由玩家处理，清空后出站；到站免费满修；出站自动无敌冲刺，战中单条充能满后手动释放。

以下未标注为已确认的具体规则均为本轮建议。

## 2. 一次远征的闭环

起手装配 → 出站突破 → 击败敌人并选择强化 → 验证构筑 → 到站满修与整备 → 下一段战斗 → 最终挑战 → 结算研发成果。

- 远征是一局，站间区段是这一局的阶段。进站不重置等级、经验、已选强化或废料。
- 起手保证至少一个可攻击设备，不依赖广告获得第一把武器。已解锁起手方案可预览，初期只开放少量完整方案，不要求玩家先理解全部设备。
- 普通区段按行进距离完成，HUD显示距下一站的距离；挑战段若要求击败首领，提前显示“突破首领封锁”。不把隐藏清怪条件叠加在已经归零的距离上。
- 战斗画面向上行进；达到入站条件直接进入整备页面，在该页面表现列车从左向右入站，不增加独立中间结算页。
- 入站结算本段收益，免费修复现有列车，再由玩家整备。基础收益不需要看广告领取。

## 3. 成长对象及保留范围

|对象|如何获得|到站后|远征结束后|
|---|---|---|---|
|车头、车厢、模块实例|起手装配、站内购买或补给|保留当前实例和布局，耐久满修|清除当局实例；下局按起手方案重新生成|
|车厢等级|两节同级车厢合成|保留|重置，不解锁永久容量|
|远征等级和经验|战斗击败敌人|累计保留，不每站从一级重来|重置|
|已选武器和通用强化|升级后的肉鸽选择|全部保留|重置|
|废料|战斗及明确的区段收益|累计保留，用于当局运营|清除，不默认折算研发资源|
|蓝图与研发进度|正常结算、主线目标及明确额外奖励|局外持久记录|保留|
|临时周转装备|站内合成及调整|只存在当前站内，出站前处理完|不成为永久仓库|

局外解锁蓝图代表获得使用和出现资格，不等于永久拥有某个高等级模块实例。局外研发对当局何时生效应明确；首版建议在新远征开始时应用，不在途中暗改基础属性。

## 4. 战斗强化：决定设备怎么打

### 4.1 获得与选择

战斗击败敌人获得经验，达到阈值触发三选一。废料负责站内购买，经验负责途中成长，二者职责不同，不再增加技能点货币。

- 三选一期间暂停战斗和模拟进度，不因阅读卡片受伤，也不继续计算路程或冲刺消耗。
- 当前候选主要来自已装武器类型，少量为通用强化；不在战中提供另一套英雄招募。
- 同时跨越多个等级时，依次处理选择，不吞掉已获得的升级；候选不足三项时展示实际可用项，不凑无效卡。
- 展示实际能力变化及明确前置，不只写“战力增加”。高阶变化优先体现覆盖、目标数量、攻击方式或集中处理能力。
- 未抽到理想分支时，基础强化和其他设备仍可支持推进，不把唯一稀有卡设为通关必需品。
- 首轮不引入选卡付费刷新，先验证免费构筑本身是否成立。

### 4.2 强化归属

建议强化绑定本次远征的武器类型。同类已装模块共享该类型强化，每个模块仍独立占容量并产生自己的攻击能力；不是一张强化卡自动复制模块。

例：已获得“电弧增加连锁目标”，站内新装第二个电弧线圈也享受该效果；卸下全部线圈后不再产生电弧攻击，重新安装后恢复使用已获得的强化。

- 强化同一类型一次，不因装了两件同类模块被重复结算为两层强化。
- 没有装载对应武器时，已有强化标为“未装载，暂不生效”，不删除；后续候选停止推荐该类型。
- 卸装不返还经验、不退选卡、不自动换成别的类型强化。
- 通用强化说明适用对象，不能以“全体”文案实际只强化一个模块。
- 重复模块共享强化可能导致单系堆叠过强，作为测试风险记录；不预设隐藏衰减补救。

类型分支是否互斥、高阶前置、强化上限由下一份武器分支方案规定；本轮不默认禁止混搭，也不引入洗点费用。

## 5. 站点构筑：决定带什么

推荐操作顺序：观察下一段主要敌情 → 查看当前装备与容量 → 比较补给和购买 → 装配或合成 → 处理周转 → 出站。

- 提示下一段主要威胁，例如空中群或贴车群，不要求玩家阅读精确波次表。
- 免费补给、废料购买、可选广告机会共同构成候选；各自成本明确，免费项真实可用。具体是否互斥留到站点商店规则确定。
- 获取新武器用于补短板或转型；强化旧武器用于深化路线。商店不能只剩广告升阶一条可走路径。
- 已确认的车厢合成释放车厢位置，但总容量可能降低。先展示结果，完成后由玩家自行装回、购车、出售或确认丢弃，不自动选装备。
- 后续用户修订：获取与装载分开，不能以空间不足替玩家阻止获取或观看广告；说明占用及后续处理。站内周转承接未装载物品为实施提案，详见《站点候选与前置教学方案》V0.2，替代此前先有合法位置才允许购买的建议。
- 广告奖励若涉及装备或车厢，观看前说明领取条件、容量影响及收益。容量不足时的领取处理须先完成专门规则，不能先让玩家看完再拒发，也不自动丢弃现有装备。
- 本轮不新增武器模块合成。若后续采用，先定义正常免费／废料合成路径，再定义广告支持。

## 6. 战斗结束、中断与复活

### 正常入站

入站不是整局结算。结算一次本段收益，保持当局构筑，免费满修。进站与升级选择同时发生时，建议先处理已经获得的升级，再展示可操作的整备界面，避免漏卡或后台连续弹窗。

### 通关或战败结算

建议局外研发收益按已完成的明确进度计算，结果页分别列出基础所得与额外奖励。失败仍保留正常所得，不以看广告为领取条件。

“当局废料清除”与“正常研发所得保留”同时说明；不能只写“保留全部奖励”让玩家误以为车厢和废料也带到下一局。

主动结束建议同样按已完成进度结算，无通关额外奖励；具体结算口径另列经济方案。未完成、可反复重进的片段不能重复产出结算收益。

### 广告复活候选

复活延续原远征，保留既有构筑，不把失败奖励重新领取一次；拒绝复活走正常结算。复活耐久、敌场处理、安全保护、使用上限待专项规则，不默认满血、清场或无限复活。到站免费满修不等于战败免费复活。

### 中断恢复

关闭应用、切后台或断线不是主动结束。恢复原远征阶段、装备、周转状态及尚未完成的选择，不重复发放收益或触发新的出站冲刺；暂停期间不推进战斗。复活或广告奖励的恢复需要保存明确的发放状态，不能靠重开多领。

## 7. 三段验证样本：先验证成长，再定局长

以下是原型测试结构，不是商业版最终站数。

|阶段|希望玩家理解或完成的事|如何验证|
|---|---|---|
|第一段：建立方向|看懂基础武器及一次强化效果|强化前后出现可辨变化，拒绝广告仍可推进|
|第一站与第二段：调整并深化|根据敌情补设备，形成一个清楚的能力优势|记录为何买、为何换，能否缓解对应压力|
|第二站与最终段：取舍并验证|容量紧张时决定保留、合成或转型|构筑有优势也有短板，失败原因能说清，而非只感到数值不够|

每段采用压力起伏，不只持续加怪：给强化后的发挥空间，再引入新压力检查短板。具体峰值、波次和距离配置在武器与敌人职责明确后制定。

教学首次用免费内容完成获取、装载、战斗反馈及一次站内取舍，再展示广告机会。普通玩家不应被要求先观看广告才能体验这条闭环。

## 8. 验收场景与状态

以下为后续实施验收清单，不代表已测试通过。

1. 连续两站后，等级、经验、废料和已选强化持续累计，没有到站清零。
2. 新装同类模块继承类型强化，跨车厢移动不丢失；卸下全部对应模块后停止相关攻击。
3. 转入新类型只获得其基础能力，不错误继承另一类型的专属强化。
4. 车厢合成超载不自动丢装备，玩家清空周转后可出站。
5. 普通购买失败不扣款，取消合成不改变装备和资源。
6. 进站满修不收费，拒绝广告也能整备和继续出站。
7. 战败正常结算保留应得研发收益；不把当局车厢和废料错误带入新局。
8. 中断恢复不重复收益、升级、复活或出站冲刺；站内周转物不丢失。
9. 三选一暂停期间，敌人、路程、冲刺和充能不推进。
10. 距离完成或首领挑战达成后进入正确站点／终局，不卡在零进度。
