# 车厢 L1—L3 纵向扩展线稿 V0.6

日期：2026-10-20。状态：按运行版车厢尺寸与接口节距校正，供评审。

## 采用的现行基准

- 运行版批准车厢图裁切框为776×1038，按可视宽70 B绘制时，当前长度为93.68 B，线稿标为70×94 B。
- 运行版挂点坐标（相对车厢中心）为横向±10 B、纵向13/36 B，即两列横向中心距20 B、两排纵向中心距23 B。
- 换算到车厢俯视图的局部坐标（车头端为0），当前L1两排中心约为34/57 B。为图面整数化按34/57 B绘制。
- 运行配置明确挂点中心与节距，但没有单独的统一实体底座长宽。线稿中的20×23 B框仅作接口占位单元，不声明为所有武器底座或碰撞体的真实尺寸；各武器外形/活动包络仍需按武器单独核算。

## 扩展规则

- 车体宽度恒为70 B；L1车长94 B，L2车长117 B，L3车长140 B。每增加一排，车体沿纵向增加23 B，不横向扩宽。
- L1为2列×2排/4槽，排中心34、57 B；L2为2列×3排/6槽，排中心34、57、80 B；L3为2列×4排/8槽，排中心34、57、80、103 B。
- 横向中心始终为−10/+10 B，接口节距和占位框尺寸不变；新增排保持23 B纵向节距，并向车尾方向延长车体。
- 车轮仍画在车体两侧外部，不占T面；这一版仅修正车体长度和接口网格，不改变既有轮组构图方向。

## 核验状态

- 已核对运行版 `train-body.mjs`、`vehicle-geometry.mjs` 与 `mount-layout.mjs`：可视车厢宽度/长度、游戏避让宽度及接口挂点来源已区分记录。
- 浏览器渲染目检：L1/L2/L3分别呈2×2、2×3、2×4阵列；行距保持一致，新增排位于车尾方向，三张车体比例、轮组与标注均完整显示。SVG XML与4/6/8槽数量核对：PASS。
- 实际武器本体尺寸、工作包络、车厢间干涉：未验证；本图不是物理碰撞验收。
