# 武器设计卡：外壁拒止与辐射地雷 V0.1（概念候选）

日期：2026-10-15。状态：**用户认可方向，安装尺寸、规则与美术均未定稿**。采用“车厢外壁低矮嵌入式拒止装置；辐射做成抛射并落地持续伤害的地雷”的组合，不把辐射当成推力，也不把力场伤害和地雷伤害混为一谈。

## 1. 职能和玩家可见因果

- **大类：防御。主职能：近身拒止。副效果：辐射地雷造成近距离持续穿透伤害。**
- 外壁的力场发射单元建立贴近车体的拒止边界。怪物碰到边界时，边界局部压缩并把目标向外推开；没有触界时不凭空产生击退。
- 同一装置将辐射地雷抛射到列车外侧、拒止边界之外的地面。地雷落地固定后形成局部辐射危险区，对进入范围的怪物持续造成穿透伤害；地雷不推动、不吸附、不阻挡目标。升级可以同时改变投放距离与布雷策略，但二者分开记录，不能用扩大半径伪装射程升级。
- 读图顺序：车体外壁嵌入式发射条 → 地雷从短抛射口脱离 → 落地展开/稳定 → 辐射区持续命中；怪物触碰车体拒止边界时另有一次清楚的向外受力反馈。
- 地雷放在边界外侧，目的是让被拒止的怪物仍可能进入其伤害区；地雷落点需避开车体、车轮、车钩和切割轮实体最大扫掠区。具体距离、持续时间、半径和投射频率仍需通过战斗规则确定，当前不写数值。

## 2. 装载位置与实体/效果包络

- **接口方向：车厢外壁贴装**，不是T区炮台，也不使用已废止的P助推器挂点。拒止发生在车体侧缘附近；左右侧均可作为镜像安装面，但是否两侧都能装、占用数量/容量如何尚未决定。
- 设备应由车体边梁上的承力板支撑，并跨侧壁清晰露出；不能只在车厢内部画成难以辨认的小图标，也不得成为脱离车体的漂浮吊舱。供能线/卡扣应把设备和承力板连成一体。
- 必须拆成三种包络分别审查：①外壁硬件静态包络；②力场拒止边界及目标击退位移；③抛射弹道、落雷点与辐射持续伤害区。攻击效果/力场可与切割轮攻击域有意重合，不代表硬件实体可以穿过刀盘或承力臂。
- **当前目测候选尺寸（未批准）：**内侧承力板8×10 B，锚点中心`(±33,-27.6) B`；原PNG的大块透明边已像素无损裁边另存（旧图保留）。裁边后设备本体可见高度12 B，跨侧可见宽度为拒止器12.4 B、地雷投射器13.6 B，中心`(±37,-27.6) B`；内侧与承力板约6 B搭接，外缘分别到`|x|≈43.2/43.8 B`。旧“整件8×10 B、中心±25 B”的小尺寸候选因可读性不足作废。纵向前/后净空候选各2.1 B。以上只约束页面显示和初步静态几何，不代表T格容量、装配占格或层间物理已定；轮侧遮挡、真实图片中的连接观感仍待目测，当前不宣称全局几何兼容PASS，也不接入正式装配列表。
- 刀轮与拒止场的协作规则必须明确：被挡住的怪物仍可被刀轮命中；拒止位移不能把目标瞬移穿过刀盘、车体或另一侧边界。若在同帧发生，统一判定顺序并分别显示受力与切割命中。

## 3. 正俯视美术约束

- 遵守严格90度正俯视，沿用现有列车蓝灰装甲、深色承力结构、明确黑色外轮廓与克制的旧化。拒止发射条应像车壳边梁内嵌的连续机械模块，而不是新增一层浮空光环。
- 拒止视觉只在触发瞬间局部弯折/挤压边界，并给怪物向外位移；常态边界保持低对比，避免盖住车厢和刀轮。
- 地雷是独立可数的实体：落地后短暂撑开/点亮辐射核心，地面影响区用轻量脉冲/粒子和受击闪烁表达，不使用大块不透明雾遮挡战斗单位。
- 辐射地雷配色需与青色电弧和橙铜机械部件区分；建议以小面积危险色核心配低饱和波纹，最终颜色随项目危险色表统一，不用整片霓虹紫/绿重涂车体。
- 升级遵循“发射器部件变化 ↔ 投放行为变化 ↔ 地面布雷结果变化”的对应关系。外壁硬件仍须贴合原锚点/包络，不允许靠加长外伸导轨来表达射程。
- **基础：近沿驻留雷。** 短程投放单枚可见地雷，形成局部持续穿透伤害区；和拒止边界构成车体近侧的防守层。
- **中阶方向：前置截流。** 改良蓄射/抛射机构，将地雷投到更远的敌人接近路径上，形成提前布防的持续伤害点；武器本体不变长，远投由弹体飞行路径表现。
- **高阶分支方向（二选一，不默认叠加）：**
  - **扇区撒布**：向一个接近扇区投放多枚分散地雷，形成较宽的持续伤害带；区域覆盖不等同于拒止，只有独立力场会推开怪物。每枚雷在画面中独立可数，实际覆盖由落点决定，不把它们合成一张大光圈。
  - **纵列封锁**：沿一条敌人接近路线依次布雷，形成较窄、较长的持续伤害走廊；强化装置表现为可见的分格弹仓/顺序抛射机构。
- 两种高阶策略都只让力场承担推开，雷区只造成持续伤害；若投放落点与拒止边界/刀轮实体运动区发生冲突，必须以布局规则调整投放扇区或拒绝该挂载组合，不能让地雷穿过刀盘/车体来保留视觉效果。
- 升级外观延续同一嵌入式发射条和辐射地雷核心，通过加固线圈、可见投射机构与弹仓结构体现品质；不同布雷方式必须在运行中按实际弹数、落点和先后顺序反馈。各级射程、雷数、伤害、持续时间及分支选择规则都未定。

## 4. 与现有系统的边界

- 切割轮仍负责接触扫掠伤害；拒止场负责触界推开；地雷负责落点附近持续伤害。三者可以在功能区交叠，但各有独立触发和视觉语义。
- 该组合不自动提供减伤/护盾，不削弱敌人攻击，不改变列车冲刺和武器T格容量。
- 当前穿透冲击单T候选设计卡仍作为另一个攻击类候选保留；此卡不会覆盖或删除它。
- 进入正式美术制作前，先由玩家目测当前裁边候选是否足够醒目、跨壁结构是否合理，再核对实体硬件与刀轮扫掠/车轮层级；并明确拒止场/地雷是否按每节车厢独立安装或共享整列效果。各级抛射距离和落点需另按游戏坐标设计，不能把核对页约56 B示意间隔当成运行射程。

## 5. 验收条件

1. 外壁硬件完全贴合本车壳，不漂浮、不跨车、不遮挡轮面，且经最高级切割轮实体全行程核对无硬件相交。
2. 力场只在接触边界时产生拒止，怪物位移方向明确；拒止区域与切割轮工作区重叠时，两种命中结果可分辨且结算顺序一致。
3. 地雷从装置抛出并能辨认落点、存续状态和有效伤害区；辐射伤害只施加给区内敌人，不能反向伤害列车，且不产生推开效果。
4. 严格俯视、390×844实际战斗尺度下，硬件、边界触发、地雷和DoT反馈均可读；目测验收后才能确定是否制作整套等级资产。
