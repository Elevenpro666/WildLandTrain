# ADR 0001：远征成长与区段状态

2026-09-23，执行主线M3。Journey唯一持有段号、结算记录和区段之间的成长快照；Battle在当前区段拥有经验和强化运行态，完成后同步交接给Journey，下一段复制初始化。两者不同时修改同一对象。

使用显式同步API，不增加事件总线或第二循环。Economy通过注入credit接收两次48废料测试奖励，Journey以已完成段号去重。保留旧独立Battle默认975米用作测试，远征配置1800/1800/900米。最后900米终点仅验证流程，界面明示精英尚未接入。

替代方案：所有状态放Bootstrap会混合业务与装配；通用流程框架当前无必要。回退可恢复单段装配，旧Battle默认调用兼容。M5再加入版本化持久恢复，当前不声称刷新安全。未新增平台依赖。
