## 2. 对荒野列车的规模建议

### 基础家族数量：目标5个，按位置解锁，不强行凑齐

| 规划状态 | 家族 | 位置约束 |
|---|---|---|
| 现役3个 | 机械切割、电磁传导、无人机作业 | 依既有侧向工作区/T区接口；当前美术和全列车混装审查仍有未通过项 |
| 候选2个 | 单槽镭射武器、拒止＋辐射地雷 | 镭射武器只有≤18×18 B静态T槽适配依据；拒止/地雷改用统一T面接口，运行包络仍待核算 |

因此建议首个完整武器目录上限按**5个基础家族**估算，不照搬8个大类就制作8种本体。若其中一个候选找不到可用位置，就以4个家族交付；未通过位置核算的候选不计入可生产数量。控制、持续伤害、范围覆盖可以成为现役/候选家族的升级分支，不自动单开家族。

### 升级路线与词条数量

- 统一采用**基础本体 → 两条能力路线 → 终端组合/构型**的结构。这里的三层是内容结构，不等于每种武器都必须有相同的角色等级上限。
- 现有三类家族的设计文档已有两条能力路线/家族、共12个武器专属升级节点（切割轮4、电弧4、无人机4）；全局`supply`另计，不作为武器专属节点。
- 五家族词条树V0.1按每族4个节点规划，共**20个武器专属节点**：现有三族12个保留，两个候选族各提案4个。此为内容上限，候选只有通过挂位/运行包络审查后才可进入生产；具体节点与前置关系见[五武器家族词条树V0.1](./五武器家族词条树V0.1.md)。外壁拒止/地雷的扇区撒布与纵列封锁首版二选一。
- 以参考样本38条词条对11个基础技能（约3.5条/技能）作内容密度上限参照，荒野列车按约4个节点/家族的均值规划即可；不追求每个家族填满38条或平均制造大量数值词条。

### 组合技/终端构型数量

- 现役三家族当前已有**6个升级路线终点组合**的结构：每家族两条路线各有一个前置型强化终点。这些是现有升级组合，不应全部改名包装成“超武”。
- 新增候选阶段，规划**2个终端构型**：镭射武器1个；拒止＋地雷先选扇区或纵列中的一个策略终点。另一种布雷策略等第一种在游戏中验证后再作为后续分支。
- 因此规划目录为**5家族、8个路线终点/终端构型**（现役6＋候选2）；地雷布雷策略首版只选一种，不双计。每套构型依赖2个有因果关系的节点，不为凑配方加无作用词条。
- “终端组合”可以改变攻击路径、目标分配、落点策略或防线行为，但不一定产生一个全新大型武器实体；装配位与场上实体数量仍按真实设备计算。

## 3. 等级、稀有度与平衡口径

- 不直接采用参考表T0–T3榜单。那是样本的强弱分级，容易变成环境排名；荒野列车的装配价值应由位置成本、列车容量、敌情职责和升级组合共同决定。
- 不统一规定“每武器升到几级”。当前可见的产品结构是基础装备与有前置关系的能力卡；在所有家族的路线成熟前，使用“基础/路线节点/终端构型”标识比虚构1–10级更清楚。
- 第一轮平衡只需要定每个家族的基准攻击频率/目标逻辑、升级增量、终端规则与有效工作区；百分比生命伤害、叠层上百、多个冷却等高风险效果不从参考样本导入。
- 单次升级优先改一项核心行为；若升级同时增加实体数量、范围、DoT、控制与伤害，必须拆成可辨认且可测试的前置节点，不让一个词条难以解释。

## 4. 建议生产顺序与停止门槛

1. 先完成三类现役武器资产/升级表现，继续维持当前12个节点框架，不新添同义家族。
2. 核对外壁拒止/地雷的硬件锚点、力场边界、抛射轨迹和落点禁区；不匹配则暂缓该家族。
3. 核对单槽镭射武器的真实光束/敌人贯穿规则；规则成立后再纳入数量目标。
4. 两个候选均通过装载审查后，按五家族词条树V0.1的内容上限收敛到5家族、20个武器专属升级节点、8个路线终点/终端构型；之后再依据玩家实际体验评估是否需要第6家族，而不是先画第6套资产。
