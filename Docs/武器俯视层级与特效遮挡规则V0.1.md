# 武器俯视层级与特效遮挡规则 V0.1

日期：2026-10-21｜状态：用户确认的空间审查原则；待落实到各武器的实体数据与渲染配置。

## 核心约束

俯视图上的二维投影交叠，不自动等于装配冲突。列车车体、甲板、轮组和武器拥有高度/纵深结构；只要真实占据体积不相交，处在不同层的部件可以在俯视画面中部分交叠。

空间审查必须分别回答三个问题：

1. **实体是否相撞：**比较组件的平面位置与高度范围；同一空间体积相交才判为物理冲突。
2. **武器是否可读：**允许局部、短暂遮挡；不允许关键武器被其他部件完全并持续遮住。必要时通过位置、层高、轮廓对比、描边或动作时序改善辨识。
3. **效果是否互相吞没：**攻击效果与武器本体分开设定绘制层级。效果域可以重叠，但闪光、射线、电弧、烟尘等不能长期遮住邻近武器的关键识别部件。

## 每种武器的登记字段

| 字段 | 记录内容 |
|---|---|
| 装配锚点 | T槽编号、车厢坐标、占用槽数 |
| 实体包络 | 平面范围、最低/最高高度、静态与运动范围、碰撞体 |
| 投影包络 | 正俯视下覆盖的区域；用于检查可读性，不直接作为碰撞结论 |
| 本体渲染层 | 车底、轮组、甲板、武器硬件之间的前后关系 |
| 特效渲染层 | 地面/空中/车体层归属、与本体的前后关系、透明度/时序 |
| 遮挡风险 | 是否完全遮挡重要武器、是否持续、是否可由动作/对比缓解 |

未取得的高度、碰撞体或实际渲染配置必须标为“未定/未验证”，不能用示意图推断成通过。

## 当前已知的使用原则

- 轮组与甲板武器可以有俯视投影交叠，但必须后续核对轮胎、刀盘和支架的真实高度范围与实体碰撞体。
- 切割轮扫掠、拒止场、投射物落点等是不同种类的空间：机械实体看碰撞体；力场/攻击域看玩法作用；飞行/落地轨迹看路径；屏幕重叠看辨识与渲染层级。不能把它们混为一个二维“禁区”。
- 效果层级需按具体效果设计，不以“所有特效都放最上层”作为默认规则；目标是清楚看见命中/攻击反馈，同时保留武器本体识别。
- 重要武器在静止待机与持续攻击状态都要检查；短暂爆闪可遮挡局部，但不得持续吞没核心外形。

## 当前图纸的边界

`统一T槽切割与防御模块包络登记V0.1.svg`按3 px/B示意车厢和扫掠投影。它确认的是槽阵列中心位置与平面几何，不含真实高度、碰撞体或最终游戏渲染顺序。其投影交叠只作为后续立体与可读性审查的输入，不是碰撞失败判定。

`切割轮车轮邻槽分层示意V0.1.svg`增加同一组切割/轮组/邻槽电弧的投影和概念剖面。剖面中的虚影仅表示待补数据的包络，不可当作真实Z范围。现有原型车宽74 B与当前新车厢70 B设计基线不一致，使用原型扫掠数据只能做旧参数投影参照。
