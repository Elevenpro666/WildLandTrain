# 站点候选与前置教学方案

版本：0.2｜状态：已纳入用户纠正；具体实施方案未实施。

依据：《IAA广告体验目标原则》《共同远征成长规则》《首批武器分支与战力验证方案》。广告的体验价值、真实免费比较及前置教学为已确认要求；本文件的候选组织、领取处理及教学分段为建议，不自动覆盖PRD。

## 1. 一句话规则

到站免费修好车，展示与当前列车和装备成长阶段匹配、收益清楚的商品，让玩家产生“都想要，但废料不够，需要决定先要哪个”的取舍；免费、废料购买和广告机会共同参与比较，系统说明结果，不替玩家判断值不值得获取。

本次用户确认：商品吸引力关联列车等级与装备等级；容量不足不阻止玩家观看广告获得道具；内容开放限制必须明示所需章节或等级；教学目标是让玩家快速理解“什么是强、如何变强”。列车等级、装备等级的具体模型尚待定义，不据此自动新增等级条或升阶系统。

本轮定义产品流程，不重排当前页面、不修改程序、不确定广告次数或价格。

## 2. 同场比较，不强制三选一

建议采用可组合的站点补给，而非“免费、购买、广告只能选一个”。三种获取方式共同服务当前整备，但各自条件清楚：

|类型|建议规则|玩家的实际代价|
|---|---|---|
|免费补给|从当站免费候选中选一项，具体候选数量待测试|放弃其他免费候选，并考虑装载空间|
|废料商店|按现有库存与废料购买，可与免费补给组合|当局废料与容量机会成本|
|可选广告机会|展示具体收益，玩家自行决定是否观看，可与普通获取组合|观看时间及取得装备后的容量取舍|

“免费选一项”为首测提案，不是新增已确认门槛。每件已领实物从对应库存移除，不可反复领同一件；广告机会数另行配置，本轮不设固定每日或每站次数。

领取免费补给不关闭商店，也不强制取消广告机会；看广告不没收未领的免费补给。玩家可以只拿免费、只购买、组合获取，或保留现状直接出站。

比较重点是当前目标与容量，不要求三类收益相同，也不把广告奖励做成免费项的固定倍数升级版。若额外奖励在任何情况下都无脑必拿，应检查时间打断、库存和收益设计，而非人为加一层新货币。

## 3. 按当前问题组织候选

候选随列车等级、装备等级、已装设备及章节进度匹配成长价值，敌情用于解释用途，容量用于说明代价而非过滤选择。应同时存在提高武器能力、增加承载空间、补充打法等有吸引力的目标，不强推唯一最优解。不因暂时装不下就认定商品无用或隐藏它。

“钱不够”是预算不足以包揽所有心仪商品，不是连基本成长都买不起。正常收益须支持有意义的选择，不能通过削减免费收益强迫广告；具体预算与售价另测。

|玩家处境|免费候选示例|废料购买示例|广告候选示例|比较点|
|---|---|---|---|---|
|近身怪积压|成长价值匹配当前阶段的切割轮补给|购买补位设备或新车厢|额外无人机舱，告知占用及取得后如何处理|近身覆盖、机动补位与容量成本不同|
|下一段有空中群|有实际价值的电弧补给|另一种对空设备或扩车|匹配当前车厢等级的额外车厢，明示编组与解锁条件|先补对空还是扩建；对空不能只有广告能获得|
|已有同级车厢但容量紧张|正常可用补给，不强塞装备|买车、买装备或保留废料|合成支持方向暂作候选，具体形式须先定规则|升级可能释放车厢位置但减少总容量，不能宣称必然扩容|

以上是情境例子，不是固定商店脚本。免费模块、售价、库存和出现频率待经济配置；免费内容也须保持成长价值，不能长期只给低阶无用物。暂时放不下不等于没有价值，由玩家决定是否获取再调整；不自动替换掉其心仪候选。

首轮优先复用已存在的实物模块或车厢，不添加广告币、兑换材料或万能升阶券。模块合成尚未确定，暂不承诺“看完立即合成高阶武器”。

## 4. 获取与容量处理

### 普通购买和免费模块

获取与装载分开。废料足够或满足明确领取条件即可自主获取，装不下只提示后续处理，不替玩家拦截选择；资金不足、已售出等真实交易条件需明确提示。

承接提案：复用站内临时周转承接未装载物品，允许获取后自行装载、调整、合成或处置；出站前处理完，不提供额外战斗容量。将周转范围从合成溢出扩展到普通获取、以及未编组车厢，是本轮实施建议，具体交互与车厢处置规则待定，不声称已经实现。不得以承接功能未设计为由恢复“容量不足禁止广告”的产品规则。

### 广告实物奖励

观看前锁定具体奖励，告知占用及未装载物品的处理方式，不要求先找到合法安装位置。播放期间暂停整备操作，完成后保障取得奖励。

- 没有合法位置时提示“获得后需整理装载”，玩家仍可选择观看；不能因系统认为不划算、装不下或已满编而拒绝启动。平台无广告等真实失败明确说明，不伪装为容量门槛。
- 正常完成后发放一次，再由玩家选择装载或周转处理，不自动合成、卖出或丢弃。
- 放弃或播放失败不消耗候选、不扣普通资源，恢复正常整备。
- 若播放成功但发放中断，保留该笔待兑现记录，恢复后继续兑现，不要求重看；这是异常恢复记录，不是可主动积攒的跨站仓库。
- 待兑现未处理时保留原站状态，不能重复出站或重复领。具体平台完成凭证与发放实现由后续平台方案定义，本轮不声称已实现。

当前满编不隐藏车厢商品，也不阻止获取；取得车厢与把车厢编入列车是两回事，未编组车厢不提供战斗容量。玩家自行决定后续合成或处理。

若更多编组位置受内容开放节奏限制，应展示“通关第N章解锁下一车厢位置”或“列车达到L级解锁”，并说明解锁后能多编入几节、是否仍需当局购买车厢。N、L必须来自真实配置，不能用“敬请期待”代替目标；本轮不虚构具体值，也不同时叠加章节与等级两道门槛。

更多车厢按内容进度解锁是用户提出的方向；最终编组上限已于2026-09-29确定为车头加五节车厢，起始可编组数量与具体解锁章节仍待明确。章节解锁编组位置不等于恢复车厢内部格子广告解锁，也不等于永久赠送当局车厢。

## 5. 让玩家知道为什么有用

每个候选都应说明：实际获得物、解决的问题、占用容量、获取成本，以及是否还需后续操作。不需要玩家先看广告再揭晓收益。

例：“电弧线圈：补充对空和连锁攻击；占用容量见当前配置；免费领取。”

例：“同级车厢：可与你的车厢合成；领取后需要手动合成，合成前可查看容量变化；观看广告获得。”

禁止把“获得同类物品”写成“直接升阶”，把“单节容量增加”写成“总容量必增”，或把正常满修包装成广告权益。

推荐说明可以根据当前装备变化，但不替玩家自动选广告、不强制点推荐项，也不因选择免费而弹出惩罚性挽留。

## 6. 前置教学分段

教学不是教会点按钮，而是让玩家理解强度来源及获得途径：

|变强方向|明确告诉玩家的变化|获得途径与验证|
|---|---|---|
|武器能力提升|若为武器等级提升，标明前后等级及具体攻击收益；若为肉鸽强化，标明覆盖、频率或目标数变化，不混称升级|对应获取／升级规则，随后看清怪或处理厚皮目标更有效|
|装载能力提升|单节容量变大、整列总容量变化、还可装多少武器；合成总容量可能降低也必须说明|买车或合成后比较容量并实际装载，不把空容量直接等同战斗力|
|编组位置开放|达到明确章节或等级后，可多编入车厢，仍说明购车条件|展示当前进度与下一目标；解锁不自动等于已经增添火力|
|打法补全|新增对空、近身清理或机动覆盖，解决原来处理不好的敌人|装入对应设备并在适合敌情中看到结果|

不强加综合战斗力评分；若以后显示，不能用一个上涨箭头代替实际收益解释。武器等级成长尚未落规则时，不先教不存在的合成升级。

### 第一步：免费认识设备

用免费起手设备介绍基础作用，完成装载后直接出战。只教当前需要的操作，不一次讲完六条分支。第一场先出现可被起手设备有效处理的敌人。

完成标志：玩家装上设备，并看到它实际击中对应目标。点击“知道了”不能替代效果验证。

### 第二步：强化后立即验证

首次肉鸽选择提供可理解的方向变化，选择后给一段适合的敌情，让玩家看到范围、目标数量或攻击节奏变化；不紧接着进站把收益藏掉。

完成标志：强化已经生效且有发挥机会，不要求玩家观看广告或抽到稀有卡。

### 第三步：站内比较与容量取舍

首次整备使用免费补给与正常废料购买，预告下一段主要威胁，让玩家比较补短板还是留资源。以装载预览教容量，不故意塞满全部空间逼迫丢弃。

车厢合成教学等玩家实际具备同级车厢时再出现，明确单节容量、车厢数量与总占用变化；允许取消。不能把“必须合成并损失装备”当教学通关条件。

### 第四步：介绍可选广告

基础获取、装载、战斗反馈与一次站内比较完成后，才出现首次广告价值引导。与免费和正常购买同场呈现，只解释额外收益，不用强制手指或不可关闭遮罩。

选免费、购买、广告或直接出站，都能结束这次引导。玩家拒绝后不在同一次整备反复教学；没看广告不视为教学失败。

上述是行为节点，不强制对应固定第几站。已掌握的玩家可跳过说明，但仍走同一套可用规则。

## 7. 广告是否成立的判断

每个点位填写：当前目标 → 具体奖励 → 体验改善或损失减少 → 非广告替代 → 容量影响 → 下一段如何验证。

首轮观察：候选是否被理解、免费与购买是否真的有人愿意选、广告奖励能否装载并使用、领取后是否改善目标问题、拒绝广告后是否顺畅继续。

不以广告观看率单独判优。若看完后没有安装或立即丢弃，应检查推荐与容量，不直接提高奖励倍数。分组用户存在偏好差异，不能仅凭看广告者胜率更高证明因果效果。

## 8. 验收清单及本轮记录

- 免费、购买、广告标签真实；购买不冒充免费。
- 免费候选实际可用；下一段必要应对不被广告独占。
- 领取免费后仍能购买；不看广告可以继续整备和出站。
- 容量不足仍可自主获取和启动广告，结果有承接；装载受实际容量限制，取消不损失装备。
- 广告成功发放一次，中断可恢复，失败不没收普通收益。
- 获取奖励不自动合成；合成仍允许超容量并由玩家处理周转。
- 内容锁定展示真实章节／等级目标，不因暂时满编隐藏商品；最终上限为车头加五节，开放节点待确认，无永久内部容量广告或修理费。
- 教学可以不看广告完成；玩家能说明哪里变强、如何获得提升，并观察前后差异。
