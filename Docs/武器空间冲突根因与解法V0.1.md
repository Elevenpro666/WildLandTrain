# 武器空间冲突根因与解法 V0.1

日期：2026-10-15。状态：**空间规划纠偏提案；已由现有坐标推导候选落位，需用实际车壳轮廓核实，不改运行装配。**

## 结论

空间不是“候选武器都放不下”，而是审查时把不同性质的范围一律当成必须互斥的实体占位：固定硬件、运动零件、瞬时弹道、作用效果和目标位移被混为同一类。因此攻击线一投影到车顶就被误判成穿过车体；力场效果与刀轮范围重叠也容易被误解为机械冲突。真正需要硬性禁止的是实体硬件/运动机构相交，和需要实体存在的地雷落在刀轮/车轮轨迹中。

两候选都有解法，不需先改车厢尺寸、增挂位或牺牲现有武器：穿透冲击保留单T静态本体，把瞬时攻击线作为车顶上方攻击效果；外壁装置放在车厢前端侧缘窄窗，地雷投到刀轮最外缘之外。以下坐标是候选规范，不是已接入的挂载规则。

## 根因拆解

1. **包络类型没有分开。** 旧审查把T武器的攻击轨迹当成实体占位；但挂位是车顶T底座，弹道可在其上方显示和结算，不必占用整条地面碰撞空间。反之，炮体、刀臂、刀盘、地雷实体确实需要硬性净空。
2. **用全侧壁概括了一个局部安装问题。** 刀轮扫掠占据大部分车厢侧边，但它有明确的纵向边界；前连接区之后、前排刀轮扫掠之前仍存在窄窗。没有先找这段区间，就把整条外壁判为冲突。
3. **缺少可复用的审核口径。** 当前`mount-fit.mjs`只覆盖切割轮与助推器组合，没有外壁装备、地雷落点或T武器效果的通用数据模型。缺少登记项被当成“无法证明，所以整族卡死”，而不是分别记录为待定项。
4. **本体尺寸和攻击效果范围混用。** 18×20 B T本体静态适配已通过；最大弹道/攻击效果需要设计和战斗规则，但不应因此否定本体落位。地雷相反：既有一个实体落点，也有可重叠的持续伤害区域，必须分开登记。

## 建议采用的统一空间分类

| 空间类型 | 是否需要与其他实体互斥 | 示例/判定 |
|---|---|---|
| 固定硬件包络 | 是 | 炮体、外壁发射器、底座；不能与车壳实体、车轮、刀盘、承力臂相交 |
| 运动硬件扫掠包络 | 是 | 横移刀盘、开合舱门；按最大工作态检查与固定件/其他运动件的交集 |
| 瞬时攻击轨迹 | 通常不是安装占位；需要目标/效果规则和可读的绘制层 | 冲钉弹、抛雷弹道；只有当其是持续存在的实体且会撞击友方硬件时才进入实体碰撞检查 |
| 攻击/防御作用区 | 可按设计重叠 | 力场与刀轮攻击区、辐射伤害区与切割伤害区；分别结算，不把效果重叠误报为硬件碰撞 |
| 持续存在的场上实体 | 需要与硬件扫掠及列车实体留净空 | 落地地雷；应落在轮组和刀盘实体扫掠以外，伤害半径可覆盖到其内侧 |
| 目标位移/受击状态 | 不作为装备占位，但需验证结果 | 拒止推开、贯穿命中；不得把敌人瞬移穿过车体或让效果造成错误碰撞 |

## 候选解法 A：T区穿透冲击

- **固定设备：**沿用18×20 B单格T上限；中心距20×23 B，静态横纵余量2 B/3 B，已有尺寸核算PASS。
- **避免攻击线“穿车”：**定义为车顶上方的瞬时重弹/短促冲击线，不是埋在车体内部的碰撞实体。源点从武器炮口开始，效果层绘制在车体/车顶装备上方，按弹道与敌人交点结算穿透；弹道不撞击己方车厢，也不占满整列车的实体装配空间。这是俯视画面的表现/结算约定，不需要在车体开一条纵贯全车的实体炮管通道。
- **落位偏好：**优先使用车头朝前的T格；若车厢也能安装，攻击效果保持在车顶上层并避免长时间遮住前排已装设备。单格硬件、弹道表现、伤害判定分别验收。
- **仍需定义：**弹体是否可见飞行、击中后如何继续贯穿、可命中目标上限与目标状态处理。它们是攻击规则，不是新的装配空间门槛。

## 候选解法 B：外壁拒止＋辐射地雷

现有参数：车厢约74×94 B，纵向以中心为0，车厢前端约`y=-47 B`；前连接保留区约`y=-47…-35.7 B`；最高级切割轮最前扫掠边界约`y=-19.5 B`，横向最外缘约`x=±90 B`。边界之间按2 B最小净空核算。

**外壁硬件的候选窗口：**

- **旧的8×10 B总设备包络和`x=±25 B`中心已被用户指出视觉过小，现标记为作废。** 进一步检查发现原PNG画布含大块透明留白；已将原图以像素无损方式另存裁边版本（旧图保留）。当前承力板8×10 B，中心`x=±33 B, y=-27.6 B`（板边贴车体外缘±37 B）；裁边后设备可见包络高12 B，跨侧宽度为拒止器12.4 B、地雷投射器13.6 B，中心`x=±37 B, y=-27.6 B`。内侧与承力板约6 B搭接。此为显示尺度候选，不代表容量占用规则。
- 设备纵向范围为`y=-33.6…-21.6 B`：相对连接保留区末端`-35.7 B`留2.1 B，距切割轮最大扫掠前沿`-19.5 B`留2.1 B。该结果仅是按当前候选车体坐标的静态几何核算；组件实际层级、侧轮动态遮挡和正式装配适配均未验证。
- `x=±33 B`为内侧承力板锚点，`x=±37 B`为设备显示中心的左右镜像候选。单项装备显示左右一件还是一对、承力板是否占容量以及正式挂载方式，尚未由几何推导决定，本轮不擅自定产品规则。

**地雷落点与投射：**

- 最高级刀轮最外实体边缘约`|x|=90 B`。地雷中心落点按公式`|x| ≥ 90 B + 地雷半宽 + 2 B`，放在侧向敌人接近的外侧；地雷实体固定在地面，不随车厢移动回扫入刀轮区。地雷伤害区允许向内覆盖刀轮区，二者仍分别结算。
- 以地雷最大直径16 B（半宽8 B）作为**候选上限**时，安全中心线为`|x|≥100 B`。战场坐标中心约210，折算为左/右约`x=110/310`；当前敌人侧线会收敛到约`x=100/320`。地雷中心距刀盘最外缘90 B为10 B，但扣除地雷半径后，地雷实体边缘的保守净距只有2 B。
- 当前显示候选的外侧发射口约在`|x|=43.8 B`，至`|x|=100 B`示意落点约56.2 B。弹道/落点线仅用于页面空间关系说明，不是实际武器射程或运行规则。地雷实体仍须按直径≤16 B候选上限避开切割轮实体。
- 地雷持续伤害半径可以压到刀轮攻击区内；“伤害区重叠”不等于“地雷本体与刀轮相撞”。地雷实体不需要阻挡敌人，也不拒止。

## 下一步落地顺序

1. 当前可视候选记录为承力板8×10 B（中心`±33,-27.6 B`）；设备本体可见尺寸为拒止器12.4×12 B、地雷投射器13.6×12 B（中心`±37,-27.6 B`）。地雷直径≤16 B和落点`|x|≥100 B`仍是几何候选，图示外缘到落点中心约56.2 B只表示页面坐标差，绝非攻击射程。全部待玩家目测及轮廓核实，不能当作运行常量或已批准装配规则。
2. 候选挂点与车厢轮廓的首轮可视核对页已落地：`station-prototype/mount-space-review.html`。玩家只需目测这一个可操作页面，重点看壁挂模块是否像嵌入侧壁、与车轮/刀轮位置是否合理、地雷落点是否贴近敌侧线。通过后才进入基础美术；无需把“攻击区重叠”另做成装配禁止规则。
3. T区本体按18×20 B继续设计；实现时把攻击表现与碰撞判定分离，明确弹道在车顶上层绘制。贯穿目标数/伤害等玩法参数另行平衡，不反向增加硬件占位。
4. 最后只用一组代表性实战画面目测：壁挂发射器不碰刀轮/车轮、地雷落在刀轮外侧且敌人能经过、冲钉效果覆盖车顶但不遮住列车。玩家做一次目测即可，不再为每个词条反复双屏或逐件试演。
