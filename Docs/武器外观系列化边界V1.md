# 武器外观系列化边界 V1

状态：2026-10-06 核对记录，非新增数值/等级规则。

## 现状

- 正式的武器 1～N 级、升阶消耗、跨局继承规则尚未定义，不能把已有强化卡数或车头品质当作武器等级。
- 当前可玩原型每种主武器有两条可兼修的肉鸽路线，每条为“基础设备 → 方向强化 → 高阶强化”。同类设备增加数量，不自动升阶。通用供能可重复叠层，也不是武器等级。
- 切割轮：覆盖路线是基础／加长支架／联动刀盘；切割路线是基础／强化齿刃／高速传动。两路线可组合，因此不是单一的三级外观序列。
- 当前切割轮素材只实现基础蓝刀盘与“强化齿刃”触发的高级灰钢刀盘；高速传动改变转速表现，联动刀盘改变可见挂载。不能宣称整套武器等级素材已完成。

## 美术生产口径

先以同一个基础造型和材质家族建立“基础件＋可叠加的功能差异层”：支架长度、刀盘数量、齿刃强化、传动状态各自映射到对应卡。这样兼修时能组合，不必为每种卡片组合重画整张图。

若以后确立正式武器等级，再决定是否为该家族叠加品质底材/配色/结构密度；那是独立于局内强化的轴，必须先确认等级数量、取得方式和跨局规则。现阶段不按未定义的 N 个等级批量生图。

## 当前候选与验证门槛

保留基础蓝刀盘为已认可的对照。已生成六辐蓝漆高级刀盘候选 `station-prototype/assets/weapons/saw-advanced-blue-v1-candidate.png`，原高级图不覆盖。该图尚未接入游戏、尚未在 320/390 实战尺寸和旋转状态验证，不标记通过。源图 1254×1254 RGBA；底缘仅约 8px 透明安全边，入图集前需规范化。

下一轮先做切割轮“基础/强化齿刃/高速传动/联动刀盘”的同屏系列检查，确认蓝漆、灰钢、外齿和六辐结构的家族关系；仍不引入正式武器等级。

## 2026-10-06 用户视觉基准修正

用户用截图绿框明确指出：认可的是**“强化齿刃”路线的银灰色高级刀盘**，不是链接中 `weaponSkin=bluegloss` 对应的基础蓝漆图。代码映射与此一致：有 `sawDamage` 时，`saw-mount.mjs` 采用 `saw-advanced-source-v1.png`；`bluegloss` 参数仅影响没有 `sawDamage` 的基础盘。单看浏览器 URL 无法判断战斗进行中当前显示哪一级，必须结合实际强化状态和截图。

此前把蓝漆盘升格为高级标尺、建议重做更克制基础态，是错误推断，现已撤销。当前确立的视觉关系是基础蓝漆盘与用户认可的银灰色强化齿刃盘；不要求高级盘也涂蓝。蓝色六辐高级候选保留作失败/对照，不替换已获认可的灰钢版。正式武器等级数量仍未定义，不能把这张强化图当作完整的等级系列。
