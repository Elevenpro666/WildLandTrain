# 武器强化关键结构表达规范 V1

日期：2026-10-06。状态：美术表达设计草案；不新增武器等级或改动战斗数值。依据现有《首批武器分支与战力验证方案》和已实现的强化卡，下一步必须用实际战斗尺寸验证。

> 2026-10-08 更新：下文关于`联动刀盘`前后移动和纵向导轨的段落是历史试验记录，不再作为生产方向。用户确认改为横向往复；当前卡义与数值以《武器升级部件与逻辑规则V0.1》和运行代码为准。

## 总原则

每张强化卡先回答“哪一个部件承担新增能力”，再画这个部件的**位置、形体、工作面、材质和工作状态**。变化应能让玩家推断功能：覆盖变广看支承/导向，切得更狠看刃，传得更远看传导端，打得更集中看蓄放电核心。颜色服务于材质与功能，不用随意换色或增加螺丝、线条、装饰来充当升级。车体接口和基本投影保持稳定，两条路线可兼修，视觉变化分别作用于自己的部件。

优先级：①实际作用部位的轮廓与占位；②该部位的材料和明暗；③运动/攻击反馈；④最后才是细部纹理。30px 左右看不见的零件，不承担核心辨识。强化状态与装备数量必须分开表达：买第二件武器不是武器升级。

## 首批武器映射

|武器与路线|关键结构|方向强化：应看到什么|高阶强化：应看到什么|材质/反馈职责|
|---|---|---|---|---|
|切割轮·扩大防区|车侧支架、导向与刀盘安装位|加长支架：刀盘工作位置向车外伸出，支架承力关系清楚|联动刀盘：前后工作位置和传动关系成立，玩家能区分它与“买了两件切割轮”|支架是旧化承力金属；传动部位可用不同明暗强调工作连接，但不把刀齿变亮来冒充覆盖强化|
|切割轮·持续切割|刀齿、刃缘与中心传动轴|强化齿刃：切削工作缘更重、更锋利；当前用户认可银灰色高级刀盘作为这一路线的视觉基准|高速传动：中心传动组件与旋转色带显示更高频率，实际攻击间隔同步变化|裸钢/磨耗集中于刃缘，蓝漆属于非切削盘面；当前银灰高级盘无需强行涂蓝|
|电弧·扩大传导|输出端、导电叉/传导端|延伸电弧：输出端的指向和可达范围更明确|多级传导：分叉/多端结构对应更多不同目标|金属导体与绝缘外壳分开；电弧路径的长度和分叉在真实命中时可读，而非只增加装饰电线|
|电弧·集中放电|线圈绕组、储能核心与主放电口|高压绕组：蓄能部位更厚重，主出口集中|双脉冲：同一主出口清楚呈现两次放电节奏，不误读成增加一件线圈|绕组金属与发光核心分层；亮色主要给蓄放电，不把整件武器涂亮|
|无人机·分散巡防|机舱发射位、机体数量与感知端|扩编机组：真实无人机和可用舱位数量增加|协同巡防：感知/通信部件与分散编队呼应|机舱承载结构保持同族；编队和飞行路径是功能证据，不能只在机舱贴“×2”|
|无人机·集中处理|机体电极、锁定端与攻击方向|强化电极：电极工作端更明确，命中能量集中|集中作业：同舱无人机共同转向同一厚皮目标，有共同锁定/攻击节奏|电极金属与放电亮点分开；不靠把整架无人机换色表示伤害或集火|

助推器不是攻击武器；其强化/数量需要另按喷口、燃烧、储能等实际功能定义，不沿用上述刀齿/电极语言。

## 对当前实现的处理

- `sawDamage` 的银灰高级刀盘是用户认可的强化齿刃样本，继续保留。蓝色六辐候选不能因“同色系”而覆盖它。
- `sawLinked` 已按用户决定统一为现有刀盘沿导轨前后扫切，单件始终两盘、双件始终四盘。旧轨被车体遮住、功能推断 FAIL；新轨移到刀盘外缘后，用户仍指出“有轨道却看不出攻击怎样变强”。现于游戏内让现有刀盘及连接件随模拟时间往复移动，直接表现前后覆盖；规则仍仅将每件沿轨半长30→50，伤害和攻击间隔不变。正常选卡与试演入口在320/390两宽的状态/运动检查PASS；动态审美和玩家功能理解仍需在游戏中看，不以截图代替。
- 外轨必须能读出固定承力路径：车厢侧铆接座→上下两根固定斜撑→外轨端点；导轨到刀盘的短连杆才随刀盘滑动。单组和双组共用此安装语法，不能把外轨画成只围住刀盘的独立悬浮框。2026-10-07 表现层候选已按此接入，320/390 两宽单组、双组及运动检查PASS；最终动态视觉仍待用户在游戏内判断。
- 上述细斜撑候选被用户实战截图判定仍像悬空：两排刀盘遮住斜撑，说明“几何上已连接”不是实战尺度的视觉合格标准。二次候选在两排刀盘间的无遮挡空档增加实心横梁，根部覆盖车厢侧板、末端压住外轨中心节点；小屏必须直接读到这条承力路径，不能靠放大才找到铆钉。自动与同屏目视已核对，最终玩家观感未验。
- 现有电弧/无人机的局部图标及附加件只是提示层；是否在武器本体的关键结构上读出功能尚未通过 320/390 实战验证。
- 2026-10-07 高压绕组单/双组候选已把变动落在铜绕组和青色储能芯，功能、透明图和两宽加载检查通过；但缩到游戏尺寸后与基础态静帧差异仍偏弱，**级差识别 FAIL**。这说明不能只看生成图大图或加载成功；下一次先检验命中时的储能/放电节奏，再决定是否继续调整绕组外轮廓。候选不转正式标准。
- 用户实战截图进一步说明V1多道绕组在小屏读成“数量更多”而非“单次更强”。V2曾按“每侧一道更厚绕组、中央唯一放大的核心、输出端数量不变”试演，并将强度差异落到首目标的单束亮芯命中；双脉冲是同设备再次放电，不能切换成双设备图。数量升级只由实际安装件数驱动。V2现已被用户判定级差不足，保留失败记录。
- 用户随后在游戏内判定V2与前版差异仍不明显，V2视觉候选资格撤销。V3先用原基础电弧加独立的、大面积储能罐层验证实战尺度结构识别，保留两侧电极和首目标集中放电；这只是程序形状样机，不因自动测试PASS就视作正式美术。验收还必须确认它读成“原电弧武器增强”，而非车上多装一块无关电池。
- 2026-10-07 的新独立武器方向中，用户把“多道连接线圈”进一步明确为**从圆形能量核心到左右原攻击端各有一条连接通道，强化时在每条通道上方再并联一条完整传导通道**。这不是同一轴上增加铜环/线圈匝数，也不增加炮口或装备件数。上一张只增铜环的双线圈图已判退；双并联通道图目前只作大图视觉候选，尚未替换运行资源，也未锁定对应哪张卡或实战尺寸级差。

验收时每条路线单独问：遮住卡名后，玩家能否从关键部位和工作反馈猜到是范围、伤害、频率、数量还是集火？若只能说“更复杂/更亮”，该外观不通过。两条路线兼修时，应看到两套部位变化并存，而非一张泛用高级贴图覆盖全部。
