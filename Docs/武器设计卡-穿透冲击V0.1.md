# 武器设计卡：穿透冲击 V0.1（候选）

日期：2026-10-15。状态：**位置与职责候选，未批准制作美术或接入玩法**。本卡依据当前T/L/R挂载规划及已知包络筛选；只确定一项落在现有接口内的攻击武器，不为填满职能表而扩张挂点。

## 1. 位置审查

- **装载区：T区单格**，使用现有2×2四格阵列中的一个通用底座；本体最大显示包络按`18×20 B`控制，不跨格、不借用邻格、不外伸支架。
- T格尺寸关系已有几何核算：中心距20×23 B、单格底座最大18×20 B，相邻底座留2 B横缝/3 B纵缝。此结论仅证明静态底座尺寸匹配，不代表该新武器的游戏内识别或安装关系已经验收。
- **L/R侧梁暂不采用**：现有最高级切割轮横向工作包络达到侧梁区域；装配总审查仍为FAIL，不能把侧梁视为无冲突的通用空位。
- **P区不采用**：助推器已退出玩家装备系统；旧P坐标/试演记录不能作为新武器挂点依据。
- 本体内部的蓄压/储能机构和单个发射口都限制在T格。弹体离开发射口后的攻击路径属于攻击效果，不计为实体装配占位；其命中视觉不得遮住相邻T武器的本体。

## 2. 职能与玩家识别

- **大类：攻击。主职能：直接伤害。副标签：直线穿透、重甲优先（具体目标规则待战斗数值设计）。**
- 目标问题：稳定处理一条攻击线上高耐久/装甲目标，补足切割轮近身横扫、电弧目标间传导、无人机自主索敌三种现役行为。
- 载体：短行程工业冲钉器/电磁蓄能冲击器，采用紧凑的T格顶视机身、一个清晰的前向发射口和可见的蓄能腔；不画成长枪管，不使用手持枪比例或三分之四透视。
- 可见因果：蓄能腔短促亮起 → 单枚粗实冲击钉从前向发射口高速离膛 → 命中后穿过首个目标并在后方留下清楚的贯穿反馈。若玩法只允许命中单体，则移除“穿透”标签和贯穿表现，不能只靠光效宣称穿透。
- 与电弧区分：冲击钉沿一条直线贯穿目标，不在目标之间跳电、不分叉；与切割轮区分：不靠贴身接触和横向往复；与无人机区分：固定挂载、非自主追踪。

## 3. 升级延续规则（方向，不是数值承诺）

- 保留同一T格底座、中央蓄能腔、单一发射口和正俯视轮廓；升级只强化机身内部导能/蓄压部件，零件不越出18×20 B包络。
- 外观可从基础的单段蓄能腔，发展为可见的叠层导能环/压缩腔与更明确的锁定结构；不增加并列发射口或虚构五路分配器。
- 攻击反馈同步体现真实升级：只有规则增加穿透层数时，弹体才贯穿更多目标；若只增强单目标伤害，则只强化命中/装甲破裂反馈，不额外增加弹体数量或分叉。
- 等级、伤害、射速、穿透目标数、蓄能时长均未定；需在战斗规则与升级组件卡中另行确认，不从美术层反推数值。

## 4. 本轮筛选结论与未选项

| 职能/方向 | 当前接口判断 | 处理 |
|---|---|---|
| 单体直线穿透 | T区已有单格18×20 B接口；紧凑固定本体可在格内完成 | 保留一个候选设计卡，待产品与战斗规则确认后才制作 |
| 近身拒止＋辐射持续穿透伤害 | 功能区会覆盖车体周边/邻近区域；现有资料没有已批准的力场空间边界、触发方式或适配挂位 | 暂不立项，不把辐射塞入T格并假设自动覆盖整车 |
| 大范围持续伤害/喷射控制 | 需要持续喷流、残留区或侧向摆扫包络；L/R与切割轮存在工作区冲突，T区也没有对应动态净空证明 | 暂缓，先解决挂载分区及包络，当前不画、不接入 |
| 破片范围攻击 | 可尝试T区单格弹仓，但落点/散布区和当前敌群玩法尚未有可核对规范 | 暂缓，不能仅因本体能塞进一格就判定可装可用 |

## 5. 验收门槛与下一步

进入原型前必须先定：穿透是否为真实伤害规则、目标类型优先级、弹体路径/贯穿目标上限、与敌人碰撞及多目标结算；同时以18×20 B固定本体和T格锚点核实无邻格遮挡。通过设计审查后先做一件基础视觉样板，再检查实际游戏尺寸；未获用户目测认可前保持候选状态。

当前**没有证据证明整个列车装配/运行空间矩阵已通过**。这张卡只证明候选可以采用现有T单格静态接口，不代表其他T格混装、列车侧梁或动态效果全部净空。微信真机、游戏运行与画面均未验证。
