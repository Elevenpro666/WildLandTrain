# 武器统一接口与五系尺寸规范 V1.0

日期：2026-10-21。状态：用户确认车体/槽位基线；本文将五系武器静态占位统一到单一规格接口。本文是设计规范，不代表运行版资源、碰撞或装配逻辑已完成迁移。

## 1. 已确认的载体与槽位基线

- 最大编组：1个车头 + 4节车厢。
- 车头槽数：Lv.1/Lv.2/Lv.3分别为2/4/6；车厢槽数分别为4/6/8；车头和每节车厢独立升级。
- 所有槽均为同一种T面接口：单槽包络20×20 B。车厢可视宽70 B，L1/L2/L3尺寸为70×70、70×86、70×109 B；车厢槽阵列为2×2、2×3、2×4。
- 槽中心节距为横向24 B、纵向23 B（相邻槽净距分别4 B、3 B）。所有武器装在车头/车厢顶面T槽；取消车壁武器挂点，不设侧壁槽、P槽或其他尺寸槽。
- 满编全Lv.3为6 + 4×8 = 38个同规格槽。满列竖屏图按1.20 px/B推演可放入390×844视口；其中6 B车钩余量仍是构图假设，不是工程尺寸。

## 2. “一种槽规格”的含义

接口只有一种规格，不等于每种武器必须长得一样，也不等于所有武器必须只占一个槽：

1. 单槽武器统一以一个20×20 B槽作为安装锚点。静止状态下的底座/主体应收在槽内；不得遮住相邻接口或轮组。
2. 需要更大静态底座的武器，必须占用相邻的多个同规格槽。占用多个槽时按槽中心及外缘计算总包络，禁止把一个大底座跨过未计数的槽。
3. “槽位包络”只管安装占位；武器最大运动空间、攻击通道、投射物轨迹、场上召唤单位是独立的运行包络。其可延伸出静态包络，但必须单独定义边界并检查与其他武器、车体、车轮、邻车及屏幕可视区的冲突。
4. 仅增加攻击效果/参数的升级不增加槽；增加实体硬件、改变武器占位或新增部署单位时，必须重新核定槽数与运行包络。升级不允许把硬件缩小来规避占位。
5. 融合是两件已安装武器在原槽位上的联动，不产生第三件免费实体；融合若新增独立硬件，按其实际占槽数重新审核。

## 3. 五系基础占槽和实体尺寸预算

单槽核心实体尺寸上限定为18×18 B，为20×20 B接口留出边缘余量；多槽武器按占用槽阵列的外包络核算。攻击/运动范围不包含在表内，不能把其数值冒充为“槽尺寸”。

| 武器系列 | 基础硬件/安装方式 | 基础占槽 | 静态实体尺寸预算 | 升级时尺寸规则 |
|---|---|---:|---|---|
| 机械切割 | 一套左右成对刀盘，分别锚定左右两个同排T槽 | 2槽（横向相邻） | 两个安装锚点总跨距44×20 B；每个槽内锚点≤18×18 B。外伸承力臂、滑轨和刀盘不计入锚点尺寸，必须完整记录为静态/运动硬件包络 | 导轨、往复支架、刀盘不因“占2槽”而免除净空审查；运动/扫掠超出车体或进入轮组区时必须重定结构/边界，不得默认为不同层。 |
| 电磁传导 | 高压电弧发生器，单一可辨发射端 | 1槽 | ≤18×18 B | 导能环、电容等外观升级留在此预算内；主电弧及多级分叉是攻击效果，不计作装配硬件或额外槽。 |
| 无人机作业 | 无人机舱/发射座 | 1槽 | ≤18×18 B | 双机、巡防路线等升级默认由原机舱部署；飞机数量、实体和飞行/攻击轨迹单独核算，不得视觉叠成一架。机舱本体扩容超界时再申请相邻槽。 |
| 拒止与辐射地雷 | 拒止器、地雷投射器为同一防御系下不同硬件构型，各自独立安装 | 各1槽 | 单个发射/拒止模块≤18×18 B | 拒止覆盖区、地雷弹道/落点/持续伤害区均为运行包络；抛射升级不改变槽尺寸。两种硬件同时装载时分别占槽。辐射地雷不承担推拒。 |
| 镭射武器 | 紧凑固定式前向镭射发射器 | 1槽 | ≤18×18 B | 聚束透镜、聚能/谐振组件在原预算内；新增实体超界则占相邻槽。直线光束及其穿透效果属于攻击通道，不算槽。 |

尺寸单位B沿用当前车体比例基准，不代表像素或真实世界单位。上述静态尺寸是硬上限预算；具体美术轮廓需依功能在预算内设计，不允许事后以“看起来差不多”为由扩大接口。

## 4. 最大运行包络登记要求

每个基础武器和升级形态需要登记以下数据后，才能判定槽位兼容：

| 字段 | 内容 |
|---|---|
| 安装锚点 | 载体编号、T槽编号、朝向、占用槽集合 |
| 静态实体包络 | 武器收拢/待机时的长×宽，及是否覆盖槽板 |
| 最大运动包络 | 展开、旋转、往复、开舱时最大边界；无活动件则标记“无” |
| 攻击/投射包络 | 射线/电弧/刀盘接触区/地雷轨迹和作用区；标注为攻击逻辑而非装配件 |
| 召唤单位包络 | 无人机等单位的数量、层级、碰撞半径和活动区域 |
| 冲突结果 | 对车轮、车体、邻槽武器、邻车、敌人和屏幕可读性的逐项判定 |

本文件完成统一尺寸预算，并未宣称各武器最大运行包络已经通过。未填齐上述字段的组合状态为“待核”，不能标记空间通过。
