# 敌人与地貌配色规则（初版）

日期：2026-10-06。适用范围：荒野列车的普通怪、高级怪、精英怪和 Boss 美术规划。此文定义视觉角色，不代表地图已实现丘陵／矿区玩法分区。

## 两层选择

先选地图环境（荒土、冻土等），再选该地图内的地貌层级。同一物种可保留模型／外轮廓和功能器官的位置，但身体的主色、明暗色块与局部材质要按栖息地重新配色；不能用一套跨地图不变的亮刺标记等级。

| 敌人层级 | 身体主要匹配对象 | 允许高对比的部位 | 不依赖颜色的识别 |
| --- | --- | --- | --- |
| 小怪／普通怪 | 该地图最常见的地面、植被与沉积物 | 眼、毒针等实际有功能的少量器官 | 身长、足数、运动方式 |
| 高级怪 | 同地图的丘陵、坡地、岩层等进阶地貌 | 强化的钳刃、尾针、毒囊等 | 更强壮的轮廓、攻防器官体积 |
| 精英怪 | 矿区、密集丘陵等特殊地貌 | 与技能对应的少数关键器官 | 独特器官组合、姿态与动作节奏 |
| Boss | 不强制随地貌伪装 | 根据角色与机制单独设计 | 独立轮廓、规模与攻击预告 |

“匹配”指色相家族、明度层次和材质来源相通，并非把身体做成与地面完全同色。实战仍要靠轮廓、接触影与局部明暗使怪物可读。亮色应聚焦能解释攻击方式的器官；普通装饰刺、关节和全身边缘不要平均撒亮点，否则会割裂躯体结构。

## 制作与验收

1. 先在地图图层里确定普通／高级／特殊地貌各自的色板与画法，再为对应等级的怪物分配身体色板；无对应地貌时标为候选，不宣称生态匹配已通过。
2. 锁定同物种的模型与器官锚点，身体色块、功能器官色块和轮廓分别保存；不同地图只换皮肤，不改变碰撞和战斗规则。当前整张 PNG 换图仍是过渡方案，尚未真正拆成语义蒙版。
3. 在 320／390 宽实际战斗图中分别检验普通地面、目标地貌色块和运动状态。先看身体是否属于环境，再看功能器官是否突出，最后看整只怪是否仍清楚。单图放大和配置色值检查不等于通过。
4. 出生点与 HUD 遮挡先检查位置关系；不为回避一次遮挡而改全局 HUD 布局。若出生地与等级生态相关，地貌分区和出生规则要一起设计，不以纯展示随机摆放代替。

## 当前落地边界

目前实战背景为荒土底色和装饰性深灰褐斑块，还没有可判定的丘陵、矿区等地形区域。`scorpion-highrank-wasteland-hill-v3-candidate.png`只验证“高级怪身体靠近深灰褐地貌、钳刃与尾针保持暖金对比”的视觉方向；不能说明它已在丘陵出生。旧的橙壳／亮刺版保留为失败对照，不替换用户源图。`tundra` 候选尚无目标地貌同屏，继续待定。Boss“持铁者”不套用这条伪装关系。
