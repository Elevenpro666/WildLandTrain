# 通用平台装配锚点试演 V0.3

日期：2026-10-07。承接 [V0.2](./通用平台装配锚点试演V0.2.md)。本轮处理用户两张放大截图的三项反馈；仍只在 `platformArt=carV1&mountTrial=fit2` 显示候选，普通入口不自动替换，容量/伤害/升级数值不变。

## 根因与修正

1. **助推器并非真正位于车厢边缘。** 上轮误将设备锚点 `c.y` 当作车厢画面中心。实际正俯视车厢绘制范围是 `c.y-20.8` 到 `c.y+72.8 B`；上轮前排 `c.y-34` 已在车体外，`x±47/57` 又把本体推离边梁。现改为本车厢纵向 `c.y-5` 和 `c.y+62 B`、横向 `c.x±45 B`，根座在 `c.x±36 B`，9 B短连接。四件在同一车厢侧缘前后各一，不以长外伸轨道占位；前后两排原画轮位约 `c.y+12/+42 B`。390静帧目视不遮轮。喷流工作态及相邻编组动态净空仍未验证。
2. **用户看到的是旧无人机舱。** V0.2 新舱只接 `mountTrial=fit2` 试演分支，普通游戏 URL 缺此参数会显示旧 `drone-bay-source-v1.png`。这是候选入口交付不清，不是新图已经全面替换。现在实际游戏也可带 `platformArt=carV1&mountTrial=fit2` 查看，试演页三舱仍各占一块T，默认游戏资源未更换。
3. **美术级差不足。** V0.2 的大圆核心、重装甲叉口电弧与厚门无人机舱标为高阶候选，不做基础态。内置 ImageGen 重新从文字生成基础电弧 `美术设计/M18电弧挂载验证/电弧单板基础叉口原创候选V1.png`，保留一个窄能源片、一条铜导路、一对朴素发射叉；基础舱 `美术设计/M18电弧挂载验证/无人机单格基础舱原创候选V1.png`，保留单个大开口、两片简单侧门和小状态灯。两张均为1254×1254透明RGBA；未以旧图做图生图。候选默认显示基础态，`mountArtTier=advanced` 可切到上轮高阶图；这是美术A/B开关，不等于正式等级规则。

生成提示词摘要：基础电弧为“90°正俯视、单T方形底座、两螺栓、窄青色矩形能源片、仅一条铜导路、朝右双叉发射端、简洁初级结构、透明背景；禁止大圆反应堆/重装甲/长横杆/侧视”；基础舱为“90°正俯视、单T独立舱、黑色矩形开口、两块简单侧门、小青色状态灯、简洁初级结构、透明背景；禁止厚门/复杂机械/数字/多舱”。两者都通过内置 ImageGen 文生图，保留 V0.2 高阶候选原文件不覆盖。

## 验证

- PASS：390×844 候选/默认六组装载测试、候选高阶图独立切换断言、助推器中心在对应车厢绘制纵向范围且根部靠侧缘的坐标断言；网页客户端在试演页及真实游戏出发后截图/状态检查；默认320/390远征胜负重开回归。
- 目视：静帧新助推器不再有伸向画面两侧的长杆，也未与车轮重叠；基础和高阶两套大图结构级差明显。三座基础舱在游戏尺寸下都出现，但舱口偏暗，玩家瞬读性未通过最终验收。
- 未验证：四助推器冲刺喷流与后一节车厢净空、武器升级如何映射美术档、微信真机。美术分级不修改现有机制。
