# 无人机飞行本体 V2 候选

日期：2026-10-08  
状态：已替换游戏运行引用；玩家小屏确认待完成。

## 本轮目标

替换战斗中仍显原型的飞行无人机本体；机舱、无人机数量、移动、索敌、接敌伤害与攻击反馈不在本轮重做。

## 设计约束

- 严格正俯视、透明单体图，游戏尺寸保持约36×19场景单位。
- 从零设计紧凑四旋翼护卫机：四个带护环的旋翼、短而明确的承力臂、中央装甲舱与传感器；不借旧飞行无人机图做形状参考。
- 使用列车的蓝灰漆面、炭灰结构、旧白钢边件、少量锈蚀和粗黑描边；列车车厢图只作材质/配色参照。
- 保留足够大的外轮廓和稀疏细节，使旋翼数量与机体在实际尺寸仍可辨。
