# 车厢 L1—L3 紧凑尺寸扩展线稿 V0.8

## 本轮目标

按用户最新意见，把车厢纵向长度收至与T面槽组相贴合的程度，为手机竖屏显示多节车厢留出更多空间。只更新概念线稿与尺寸依据，不修改运行时车厢贴图、碰撞、相机或装配规则。

## 尺寸依据

- 车体可视宽沿用现版：70 B。
- 现版车厢贴图裁切为776×1038像素，按70 B宽折算长度约93.68 B，线稿历史基准取整约94 B。
- 现版T面四槽中心为横向±10 B、纵向两排间距23 B；两列中心距20 B。
- T面安装板沿用当前四格平台图比例估算为约15×18 B。该尺寸是美术比例折算，不是运行时碰撞盒或武器净空数据。
- 本图以槽组纵向包络加两端余量推导长度；同时设置车厢纵向长度不小于70 B车宽的轮廓下限，避免基础厢短于自身宽度。L1槽阵列在车厢内居中；10 B端部余量是L2/L3的候选值，并非已确认正式规范。

## 候选尺寸

| 等级 | 槽位排列 | 槽组纵向包络 | 车体候选尺寸 | 相对当前约94 B基准 |
|---|---:|---:|---:|---:|
| L1 | 2列×2排 / 4槽 | 18 + 23 = 41 B | 70×70 B | 缩短约24 B |
| L2 | 2列×3排 / 6槽 | 18 + 23×2 = 64 B | 70×84 B | 每加一排增加23 B |
| L3 | 2列×4排 / 8槽 | 18 + 23×3 = 87 B | 70×107 B | 每加一排增加23 B |

校核说明：中心距为23 B，安装板沿纵向占18 B，因此相邻板之间净距为5 B；槽组总包络分别为41/64/87 B。L2/L3两端各留10 B后分别为84/107 B；L1按槽组包络推得61 B，但因小于70 B车宽，采用70 B长度并将槽阵列居中（两端各14.5 B）。实际端头结构仍需正式车体美术确认。

相较此前约94 B的L1基准，紧凑L1候选每节减少24 B；若编组中有4节L1车厢，车厢段理论总长减少96 B。该差值是纵向几何长度，不等同于实际屏幕像素或可视体验结论，需后续结合车头、车厢连接件、HUD与镜头再评估。

## 结构表达

- 所有武器接口只在T面甲板，取消车壁武器挂点。
- 车宽70 B、槽位横向列距20 B和纵向排距23 B不变；L2/L3各增加一排。
- 轮组保持车体外侧，按每节车长约25%/75%布置；不得进入T面槽位。
- 该图不代表所有武器静态外形或攻击/运动包络均已通过验证。
