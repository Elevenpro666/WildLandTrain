# 电弧放电特效试演 V0.1

日期：2026-10-08  
状态：已接入标准网页游戏；V0.1动态电弧与V0.2粗细级差候选待玩家目测

## 目标与范围

替换旧的静态折线路径示意，让玩家在命中时看见电荷从现有发射端跳跃至目标。只修改Presentation的命中特效；不改武器本体、伤害/间隔/射程/链距/目标数、命中时序或敌人状态。

## 当前表现

- 主弧由多个随模拟时间轻微跳变的锯齿段连接发射点与目标，路径端点仍服从战斗命中记录。
- 青蓝离子通道与较宽低透明度辉光叠在白亮核心下，命中端附加短促闪环与亮点。
- 主弧旁仅有两条短细侧向毛刺；它们是特效局部细丝，不代表新的武器输出端或额外链路。
- 基础、高压强化和双脉冲命中共用表现，双脉冲仍由原模拟时钟延迟0.15秒触发第二次命中。
- 每次表现只读取已有命中事件和模拟时间，无独立循环/计时器、无Math.random，不影响战斗状态。

## V0.2：功率等级粗细

当前没有独立的电弧装备等级字段，因此采用唯一直接提高单次主击输出的现有卡`arcDamage`作为粗细映射：

| 命中类型 | 规则来源 | 电弧视觉粗细 |
|---|---|---|
| 基础主击，12伤害 | 基础态 | 细：辉光12、通道6.5、白热芯1.9（展示坐标单位） |
| 高压主击，18伤害 | `arcDamage` | 粗：辉光17、通道9、白热芯3.1 |
| 高压双脉冲第二击 | `arcDamage`+`arcPulse` | 沿用高压粗度，区别仅为第二次命中时序 |
| 连锁目标，8伤害 | `arcReach`/`arcCount`仍为链路伤害 | 保持基础细度，不让范围/目标数看成能量增强 |

该映射不新增通用武器等级或升级卡，也不改任何战斗值。若以后正式定义了独立武器等级，再将功率层级统一接入，不在本轮臆造。
