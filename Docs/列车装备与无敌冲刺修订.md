# 列车装备与无敌冲刺修订

版本：0.1。按用户最新反馈修订设计，不修改代码。已确认要求：装备体现列车世界观而非步枪等单兵枪械；加入无人机；每次出站自动获得无敌行进阶段，冲出一段距离后冷却，战斗过程中充能，满足条件后玩家手动释放。

> **冲刺规则已更新（2026-10-15）**：第3节“车头品质和相关装备决定冲刺距离”中的装备加成部分失效。助推器退出可装配系统；仅车头品质决定冲刺距离，并分为整备站出站冲出、路途中主动冲刺两档。此文其余冲刺生命周期约束继续作为历史兼容规则，具体迁移边界见[武器系列化与车头冲刺能力边界 V0.1](./武器系列化与车头冲刺能力边界V0.1.md)。

## 1. 列车装备方向

采用安装在通用车厢上的工业重装备，表现动力接口、固定底座与工作机构，不采用持枪兵种或简单把枪放大。下表为待验证设计提案，不是用户已确认的装备清单。

| 装备提案 | 工作方式 | 主要作用 |
|---|---|---|
| 侧置切割轮 | 车侧伸出旋转刀盘 | 清理贴车地面怪，强调接触范围 |
| 蒸汽冲击装置 | 向车侧喷出高压蒸汽 | 近距离范围打击和推离 |
| 电弧线圈 | 对范围内敌人放电并有限连锁 | 对空与群体打击 |
| 车载投爆器 | 抛射工业炸药至地面区域 | 远程范围爆破，有落点预警 |
| 冷媒喷射装置 | 喷出冷媒减速并积累冻结 | 减缓接敌，与其他装备协作 |
| 维修机械臂 | 修补列车受损结构 | 战斗中恢复耐久 |
| 无人机舱 | 放出自主作业无人机 | 机动处理车侧和空中威胁 |

原步枪、霰弹、机枪及其伤害/射速表停止作为首测实现依据。新装备需根据接触范围、覆盖面与实际攻击方式重新定价和计算伤害，不能机械沿用旧枪械数值。车载投爆器是否保留原炮击参数、冷媒是否沿用冻结数值均待重测。

## 2. 无人机首测建议

无人机舱占模块容量，无人机本体不额外占车厢位置。首测建议采用自动跟随、自动寻敌的电击无人机，不要求玩家持续拖动或瞄准。具体体积、售价、数量、攻击范围、伤害、可否被摧毁及补充成本待定。

无人机随列车移动，活动范围以列车为参考，不因高速冲刺滞留屏外。进站后停止攻击并回收；无人机舱移除时清理对应实体，不能残留免费火力。无人机不负责触发玩家的无敌技能。

## 3. 无敌冲刺状态

建议把自动出站和手动释放共用同一套冲刺能力：

出站自动冲刺 → 冲刺结束 → 战斗充能 → 充满待命 → 玩家手动释放 → 再次冲刺。

充能就是冷却，只有一套恢复进度，不设置额外冷却计时或第二个释放门槛。

- 每次真正离开站点进入新战斗段时触发一次自动冲刺，不因暂停恢复或重复回调再次触发。
- 冲刺时列车向屏幕上方高速行进，车头与车厢免受敌方伤害。无敌不等于免费治疗，入站恢复仍是独立规则。
- 冲刺距离由车头品质和相关装备决定。具体品质档位、装备加成和计算公式待定，不自行新增品质养成系统。内部使用逻辑距离，不绑定设备像素；界面应在更换车头或装备时展示距离变化，实际表现与预览一致。
- 冲刺结束后恢复当前遭遇所要求的正常速度，不固定强制切换到某一低速阶段。
- 只显示一条充能进度，充满即准备就绪，玩家点击释放；不自动触发，也不显示额外冷却条或满能后再等待的倒计时。
- 暂停和切后台不推进距离与充能。手动点击的重复请求不能重复扣能或叠加无敌。

建议首测按有效战斗时间推进唯一的充能进度，冲刺结束后从空开始充能，冲刺期间不积累。充能来源、速率和跨站处理方式仍是待定方案；不能再另加独立冷却机制。每次出站自动冲刺的既定规则不变。

## 4. 与遭遇机制的边界

普通地面怪不能追上冲刺列车持续造成伤害。贴车怪是否被甩落、冲刺是否造成碰撞伤害、飞行怪是否继续跟随，需明确后再实现，不由无敌自动推导。

断轨和不可通行路障是物理通行条件；无敌不自动等于可以穿越。临停时技能是禁用、仅提供防护，还是能破障突围，需在遭遇规则中选定。Boss阶段是否允许高速位移也待定，必须有明确按钮提示。

## 5. 文档替代与验收边界

本修订替代历史 PRD 中“无人机不进入V1”的限制，以及旧首测方案以单兵枪械为主体的装备方向。旧模块体积、价格、初始双步枪配置和输出比较暂停使用，车厢容量与购车首测参数不在本轮改动。

固定阶段时间线中的高速段不能代替本次充能能力。是否保留关卡脚本突围需后续统一，避免免费高速与手动技能重复发放。

后续验收至少检查：出站只触发一次、无敌实际拒绝伤害、品质和装备影响距离且与预览一致、距离达到后退出、只有一套充能进度且满能就绪、玩家不点击就不释放、后台不充能、无人机不残留、障碍规则不被无敌绕过。当前只完成设计修订，没有实现或实测证据。
