## 本阶段直接定案

1. 战斗常驻：耐久、到下一站／Boss 的距离、五段单行遭遇路线、冲刺充能和释放入口。当前遭遇以箭头＋深底标识，已通过以勾号标识；不隐藏后续精英和 Boss 名称。
2. 状态按需：常速不额外占一个标签；高速无敌、Boss 禁止冲刺、充能完成等需要改变玩家决策的状态即时展示。Boss 锁定保留明确文字和不可释放按钮。
3. 收益反馈短显：经验和废料在掉落位置出现，由已有约0.8秒的模拟时间窗口退出；不把逐次掉落和累计废料同时固定在战斗 HUD。
4. 构筑反馈短显：选卡后显示强化名称，沿用约1.8秒模拟时间；若战斗暂停，反馈时间冻结。累计强化列表在暂停详情查看，不覆盖列车。
5. 冲刺反馈：正向累计的本次冲刺米数只在冲刺中及结束后短暂停留，沿用约2秒停留＋0.5秒淡出；不改成倒计时。已充能百分比保留在底部，冲刺距离上限在暂停详情查看。
6. 主动查看：暂停面板呈现精确经验、击败数、累计废料、已选强化和冲刺距离；暂停不推进战斗。三选一仍独立暂停并要求选择，不与详情面板混用。
7. 布局优先级：列车和直接威胁高于非紧急提示。顶部信息不加整条不透明横带；侧边短提示不得横跨车头。320与390宽都按完整车头＋五节验证；不为放 UI 调大车体或改战斗数值。

## 不再作为逐项确认的事项

- 上述提示的秒数、边距和字重是可测试的表现参数。发现遮挡、过短或过长时直接调整并截图回归，不为每个像素或时长停下征询。
- “玩家是否一眼理解”和微信真机可读性属于待执行的验证，不是能靠文档拍板的产品选择；未测前标记未验证。
- 用户已经决定车头＋五节、全屏战场、单行五段路线、向上行进、正向冲刺里程。旧文档里相反的“待确认”不重新发问。
