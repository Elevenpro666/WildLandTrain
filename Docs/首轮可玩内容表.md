# 首轮可玩内容表

版本：0.1｜状态：内容编排提案，尚非已可玩的版本。

依据：《共同远征成长规则》《首批武器分支与战力验证方案》《站点候选与前置教学方案》V0.2。用户已确认原则优先；下表的关段安排、起手组合与预算目标为首测建议，不是原作数据或最终关卡配置。

> **内容边界更新（2026-10-15）**：表内“动力助推器”作为可获设备的旧提案已撤销；它不再进入商店/装配/装备强化。冲刺属于车头品质能力，分整备站出站与路途中两个档位。现役装备范围以[武器系列化与车头冲刺能力边界 V0.1](./武器系列化与车头冲刺能力边界V0.1.md)为准。

## 1. 本轮样本要回答什么

玩家能否在一趟远征中体验：基础武器能打 → 强化后明显更能打 → 到站看见多个想要的商品 → 用有限废料与容量决定先发展什么 → 下一段证明选择的价值。

先做三个连续战斗段、两次中途整备及一次最终结算的内容样本。三段不是三个章节，也不固定商业版局长；章节解锁表独立制定。

全程允许不看广告。广告增加可理解的机会，不替代基本成长。武器与容量的变化必须有实际效果，不以综合战力数字上涨代替。

## 2. 最小内容范围

|内容|本轮样本安排|边界|
|---|---|---|
|列车|车头与通用车厢，支持购买和同级车厢合成|起始数量、等级容量另配；最终上限未获修改前沿用既有约束|
|起手设备|教学样本建议切割轮＋电弧线圈|装得下是起手配置验收条件，不强迫照抄旧体积数值|
|可获设备|切割轮、电弧线圈、无人机舱、动力助推器|不提前加入未定义的武器升星材料或广告专币|
|武器强化|既有十二张分支提案|短链前置显式显示，次数与候选池容量须匹配|
|敌情|拦截贴车群、厚皮地面怪、飞行群、分散混合群、终段追击精英|首轮不依赖未明确的断轨破障或强制停车|
|站内获取|免费候选、废料商品、可选广告奖励|临时装不下不禁止获取，取得与编组／装载分开|
|结束|成功结算、失败结算、中断恢复|广告复活细则未定，不把复活做成本样本通关依赖|

起手两种武器用于展示近身与对空差异，也避免玩家因未买指定商品而完全没有对空能力；不能据此让系统自动替玩家保留设备，出售或替换仍由玩家决定。

## 3. 连续体验编排

|节点|场上发生什么|成长机会／决策|要看到的变化|
|---|---|---|---|
|出发准备|免费展示起手设备及容量|认识每件武器负责什么|知道切割轮管近身、电弧能对空；容量是可装数量，不是伤害|
|第一段：出站|冲开站外围敌群，高速后回到常态|观察冲刺距离与一次充能规则|冲刺是突围能力，不是武器升级或额外冷却|
|第一段：认识火力|少量路侧拦截怪，随后有小股飞行敌人|基础设备自动处理|看清每种武器实际打到谁|
|第一段：首次成长|经验触发选卡，暂停模拟|教学候选提供已装武器的清楚方向变化|选后同类敌情再出现，观察覆盖、单次伤害或传导差异|
|第一段：短暂承压|多点贴车与间歇飞行交替，随后缓冲|可用冲刺自选释放，不强制点击|形成“哪里还不够强”的具体问题，而不是必然受伤|
|第一站|满修，预告下一段有分散与厚皮目标|比较扩车、补无人机、增加现有火力|钱能买到有用成长，但不能包揽全部心仪商品|
|第二段：兑现购买|先给一组混合目标，保留展示时间|新设备与旧强化共同发挥|若买了空间但未装武器，不伪造火力增长|
|第二段：深化|密集群与厚皮目标分组出现|方向卡或满足前置的高阶卡进入选择|清群或集中输出形成可辨优势，不保证每局按时抽到特定卡|
|第二段：检查短板|分散目标进入，压力随后回落|观察集中与巡防、覆盖与伤害的取舍|玩家能解释下一站想补什么|
|第二站|满修，预告终段持续追击与混合压力|购买、合成、补位、保留资源或广告额外获取|出现多个成长目标，不强迫指定合成或装备丢弃|
|第三段：最终兑现|先提供一段普通混合战斗|使用已成型路线或可用的替代路线|最后一次整备与强化有实际发挥空间|
|第三段：终段验证|可跟随列车的追击精英伴随间歇杂兵|自主使用冲刺，持续自动战斗|考验厚皮处理与周边清理；不要求所有武器满配|
|结算|完成或失败后展示所得|解释本局清除对象与永久研发成果|知道下局从哪种方向继续成长，不看广告也领取正常所得|

终段追击精英为测试遭遇提案：提前说明胜利条件是击败它，不先显示距站归零再暗加条件。必须保持可交战，不靠跑出屏幕或冲刺绕过结算，也不能临时禁用冲刺。其追击与高速相对运动需在实现前配清；本表不把该描述等同已实现Boss机制。

## 4. 升级与压力不是两份互不相干的表

原则：先安排成长能发挥的窗口，再安排检查短板的压力；不是每次升级立即同比强化敌人，让玩家永远感觉没有变强。

- 经验仍由战斗获得，不因进入表中某一节点凭空再发一次等级奖励。表格给出期望观察窗口，经验阈值由后续配置实现并测试。
- 首次方向强化应在第一段仍有充足敌情时出现；第二段应有深化机会；第三段后部主要验证已有构筑，不把核心成型卡集中放在结算前。
- 教学允许固定候选用于清楚展示，普通对局采用正常随机池。两者分别测试，不能以脚本必出证明随机成型率。
- 成型未完成也要测试可用路线，不人为补发指定卡掩盖问题。若正常击杀速度下长期没有成长，调整经验、敌人组织或段长，不把广告作为补偿条件。
- 同一进度下，对比强化前后类似敌情，才能判断收益；只拿第一段小怪与第三段精英比较不能证明没有成长。
- 三选一期间距离、敌人和冲刺冻结，跨站经验与强化保留，进站处理不漏掉已获选择。

十二张专属卡存在池耗尽风险：后续数值表必须同时列出可获得的选择次数与各构筑可用卡数。若次数超过当前池容量，须先设计明确的有效后续选项或调整内容范围；不能实现为重复无效卡、静默吞升级或强迫玩家购买新武器。

## 5. 两站商店如何做到“都想要”

候选价值依据列车和装备的实际成长阶段更新，不只随站数加价格。等级模型未定前，样本先按已装能力、车厢等级和明确的配置档位编排，不额外制造一条“商店等级”。

|站点|同时值得考虑的目标|免费与广告位置|预算验证目标|
|---|---|---|---|
|第一站|无人机补分散目标；额外同类设备增加火力；新车厢承载更多设备|免费补给有实际作用；前置教学已完成才介绍可选广告，未完成则继续普通流程|正常收入至少支持一条有效成长路径，但不足以把全部理想组合买齐|
|第二站|深化主力配置；购车准备合成；补足弱项；助推器延长突围|广告可以支持当前升级目标，也可以提供其他有价值物品；免费不降为无用陪衬|不同预算分配都应有可解释收益，不把唯一必要应对放在玩家必然买不起的位置|

“买齐”按可同时成立的理想采购清单计算，不能把互斥免费项相加制造虚假的资金缺口。逐项展示价格、占用和收益，玩家自主保留废料或获取后再整理。

同类设备增加的是实际模块数量；它不自动等于武器升阶。车厢合成提高单节容量并释放编组位置，可能降低总容量；商品文案不能统一写成“战力大增”。武器等级与合成尚未定义的商品先不承诺效果。

获取与使用分离：容量满仍可取得广告奖励或购买物品，具体站内周转承接需实现后验证；不自动丢弃，不把未装载物品变成免费战斗火力。拥有未编组车厢与解锁更多编组位置分别解释。

## 6. 教学是否有效，问这四件事

|教学节点|玩家应能回答|效果证据|
|---|---|---|
|第一次强化后|这次是哪里变强了？|指出具体范围／频率／伤害／目标数变化，并看到对应效果|
|第一次购车或容量预览|空间增加后怎样变成火力？|知道还要装武器，不把空车当伤害提升|
|合成预览出现时|单节变大是否等于总容量变大？|看懂前后容量，可选择取消或自行处理装备|
|内容解锁提示出现时|我要完成什么，才能多编车厢？|能说出真实配置的章节或等级及解锁结果|

教学不是考试门禁，上述问题用于测试访谈，不答对也不能卡住玩家。系统说明结果与途径，允许玩家尝试不同选择。

章节解锁提示只在有真实开放配置后投入玩家版本；当前N章／L级仅是设计占位，不能作为产品承诺。起始编组数量、各节点和最终上限需单独明确；本样本不自行写死为第三章或某个等级。

## 7. 最小测试对照

建议分开记录以下样本，不只录一条理想路线：

1. 全程不看广告：检查正常成长、两站购买和结算均成立。
2. 同预算优先火力与优先扩车：比较当段收益及下一站发展空间，不能预设哪条必须赢。
3. 单系深化与主副混搭：检查敌情是否真的产生不同优势，避免全程唯一必选。
4. 未获得预期高阶：观察基础方向与补位是否仍有发挥，不承诺所有随机结果通关。
5. 满容量获取广告物品：确认可观看、奖励兑现、有站内承接、玩家自行处理。
6. 满编获取车厢与查看解锁目标：确认获取不被拦截，编组限制清楚，未编组车厢不贡献容量。
7. 中断恢复：选卡、站内周转、广告发奖分别恢复，不重复奖励、不遗失物品。

每段记录：实际战斗时长、路程、选卡节点、强化前后效果、伤害来源、贴车积压、冲刺使用与结果；每站记录：进站废料、想买什么、实际采购、容量变化、广告选择及原因。战斗与阅读／整备时长分开统计。

上述均为待执行测试；不报告通关率、成型率或广告效果达标。
