# 荒野列车武器体系重梳理 V0.1（结构方案）

日期：2026-10-15。状态：**体系结构提案，不改当前战斗实现/数值/装载规则**。参考用户提供的技能表结构（基础装备、升级词条、前置关系、终端超武、分支策略），只借鉴组织方式；不照搬其T0-T3强度排名、百分比伤害、具体词条或每局抽取机制。

> 五个家族的具体词条、前置关系与终端构型见[五武器家族词条树 V0.1](./五武器家族词条树V0.1.md)；样本计数及项目规模口径见[武器数量与升级规模评估 V0.1](./武器数量与升级规模评估V0.1.md)。外部样本计数和项目建议分开标注，不把提案写成已批准数值。

## 1. 武器体系分层

武器目录按四层组织，避免把武器外形、效果和升级名称混成一张列表：

1. **武器家族/基础本体**：一种稳定的战斗身份，有明确安装位置、静态尺寸、运行包络、基准攻击方式和正俯视剪影。
2. **升级部件/词条**：给本体增加真实部件并改变一项实际战斗能力。伤害、控制、持续伤害、范围覆盖是效果标签，不因每个标签都新建家族。
3. **前置关系**：更深层部件需由相应的基础功能解锁；前置只表达机制依赖，不额外增加重复货币、冷却或门槛。继续沿用当前项目的升级卡关系，获取方式仍遵循既有产品流程，不照抄参考游戏的局内抽词条流程。
4. **终端构型/超武**：由有因果关系的关键部件组合形成，改变玩家能观察到的战术行为；必须由本体部件、攻击过程和目标结果共同表达。它不是单纯高数值，也不能靠新增虚构发射口解释目标数量。

每件装备登记一个主职能、最多两个副效果标签和一个/多个视觉载体。武器数量、升级等级、输出端数量、目标数、作用范围分别记账；画面不能互相代替。

## 4. 职能如何扩展而不泛滥

### 控制

控制不是默认新增一整个武器家族。冻结、减速、击退、聚拢、眩晕应分别说明目标状态变化与时长/触发。只有现有家族通过一个真实部件可自然承担，才作为其分支/副标签；否则需要独立有效挂位与不同剪影。目前没有通过空间审查的全新控制武器，不立项、不占位。

### 持续伤害

电弧重复放电、切割轮高速重复命中不自动等于状态DoT。只有目标离开瞬时命中后仍继续受伤，才标持续伤害。辐射地雷可以承担DoT；辐射本身不拒止，外壁复合装置的拒止只由力场负责。

### 范围覆盖

范围是命中覆盖形状，可与直接爆发、持续伤害或控制组合，不单独等同于一个家族。布雷可用多枚真实可数的实体和落点构成扇面/纵列区域；T区单格炮体能装入，不代表其爆炸/落点包络已通过。

### 防御

拒止、接触削弱、损伤缓冲是不同结果。防御装置必须说明其具体作用对象、触发边界、与敌人位移/列车受伤的规则；“外面有一圈光”不是防御机制证明。拒止力场的活动区可以与切割轮攻击区有意重合，但两个装置硬件不得发生实体交叠。

## 5. 升级与终端构型的统一模板

每个家族优先最多两条可辨升级路线；终端构型需要前置组合，但不要求所有路线都同时叠满。设计卡必须写明：

- 基础本体及接口、实体包络、最大工作/攻击包络；
- 每条升级改变的实际部件、战斗规则和可见反馈；
- 前置的因果依赖，以及终端构型如何组合已存在的能力；
- 终端状态下的实际数量、攻击路径/落点、持续时间或目标状态变化；
- 与邻车、轮组、切割轮等实体运动区的净空；
- 严格90度正俯视、390×844基准下的轮廓可读性与验收证据。

没有物理/动态位置的效果先保留为“未立项”；不能靠缩小美术、挤进一个名义格子、共用隐藏槽或新增随机词条把空间问题藏起来。

## 6. 当前推进顺序

1. 核算外壁拒止发射条真实锚点与切割轮全行程的硬件净空；对拒止区、投射路径、地雷落点/伤害区分别建包络。若外壁硬件找不到真实无冲突位置，就暂停这个装备，不把力场或雷体画成穿透刀盘。
2. 同时保留单槽镭射武器候选，先核对敌人碰撞/贯穿光束规则；不扩展新的安装面。
3. 以上接口成立后，再立一个家族的基础美术样板，然后按升级部件逐件扩展；目测在真实游戏页面进行，不用静态概念图替代运行验收。
