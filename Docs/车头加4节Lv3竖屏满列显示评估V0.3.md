# 车头 + 4 节 Lv.3 满列竖屏显示评估 V0.3

日期：2026-10-21。状态：用户确认车厢/单槽尺寸基线后的满编比例评估；这是一张构图评估图，不代表运行版相机或微信真机验收。

## 尺寸依据

- 视口沿用手机竖屏基准390×844px。
- 编组为1个Lv.3车头（6槽）+4个Lv.3车厢（各8槽），全列38槽。
- 车厢沿用`车厢L1-L3红框尺寸槽位线稿V0.9`：可视车宽70 B，L3车长109 B；单槽包络20×20 B，横纵中心距24×23 B。
- 车头按与车厢相同70 B显示宽度估算。当前approved车头裁切长宽比为389:728，故头车纵长估为131 B；这只是按当前贴图比例的尺寸推算，车头实体几何尚未重新定稿。
- 头车与车厢之间按每处6 B连接余量估算，共4处。连接结构尚无最终工程尺寸，因此本项为构图假设；旧V0.2按另一种草图口径计3段连接，不能直接套作现行连接尺寸。
- 全列几何纵向总长：`131 + 4×109 + 4×6 = 591 B`。
- 示意缩放取1.20 px/B；全列显示高度约709px，占844px视口约84%。示意图中车头顶端距屏幕顶约80px，末节车厢底端距屏幕底约55px（上、下空隙不相等，留出顶部HUD间距）。

## 屏幕内大致观感

- 车体显示宽约84px，计入线稿中的外置轮组后总宽约103px；左右各有约143px横向战斗走廊。
- 单槽约24×24px，38个槽可以同屏看全，但槽内小型武器细节不一定足够辨认。
- 左上耐久/等级、顶部遭遇进度与右下冲刺按钮以轻量叠层示意，没有划出固定的顶部或底部HUD带。按钮放在列车尾部右侧空位，与车体及轮组保持约5px的水平间隙。

## 判断与限制

以当前紧凑L3尺寸，全列在390×844的比例构图中能完整放入，纵向约占84%。画面主要余量在列车两侧；上下边缘有约80px与55px空间。相较上一版，新的20×20 B接口显示为约24px方槽，容量为6+32=38槽。
