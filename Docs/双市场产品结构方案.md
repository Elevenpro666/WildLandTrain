# 荒野列车：双市场产品结构方案

版本：0.1｜状态：讨论稿，未实施

## 1. 定位与依据

按本项目国内首发IAA、海外IAA＋内购的业务方向设计，不视作所有市场或平台的通用准入结论。具体发行平台与准入另行核实。

一套核心玩法与成长内容，分市场配置商业入口、权益和奖励；不是两款游戏，也不是把国内版做成缺少支付入口的海外版。

借ER的多站远征、容量与站点运营；借正中靶心2的技能分支、阶段承压与成长验证。不照搬两者具体数值或全部外围系统。

已确认约束：车头＋最多五节通用车厢（2026-09-29 用户调整）；当局买车与合成；容量随车厢等级；到站免费满修；临时周转由玩家自行取舍；无敌冲刺充能即冷却；广告必须增强具体体验或减少具体损失，与免费及其他选项一起比较，先完成基础教学。

除上述约束外，下文均为建议，不自动覆盖PRD或当前原型行为。

## 2. 三层决策与共同闭环

局外车库：选择本次发展的起手方向。

站点整备：用废料与容量决定带什么、替换什么。

途中构筑：把已装设备强化成具体打法，敌情验证选择是否有效。

完整远征建议：初始装配 → 出站突破 → 战斗与肉鸽选择 → 阶段敌情检查 → 入站满修与整备 → 后续区段 → 最终挑战 → 结算与车库研发。

站点是同一局内的调整节点，不是成长清零点。先用热身、深化、最终验证三个连续战斗段搭建验证样本；不把三段直接规定为最终商业版局长，不先定分钟数。

## 3. 获得、保留与重置

|对象|主要获得方式|跨站|远征结束|
|---|---|---|---|
|车厢与模块|起手配置、站内购买、适用的补给选择|保留，玩家可调整|当局实例清除，不扣除永久蓝图|
|车厢合成等级|当局同阶合成|保留|重置|
|武器肉鸽强化|战斗成长选择|保留|重置|
|废料|战斗及区段收益|保留供运营|结算后清除；不默认兑换局外资源|
|局外研发进度|正常远征结算、明确额外奖励|永久|保留|
|蓝图与已解锁起手选项|主线目标或研发|永久|保留|

建议武器强化绑定本次远征的武器类型，而非某个临时模块实例。移动、替换同类模块不丢强化；没有安装对应设备时不产生火力，重新安装才生效。界面文案为“本次远征：所有已装无人机舱……”。

同类多模块共享强化可能放大收益，需测试集中堆同类是否压倒混搭；先通过原有体积、覆盖重叠及敌情差异调节，不加隐藏衰减条件。

为避免解锁越多、越难抽到想要的路线，建议战斗候选主要来自已装武器，辅以少量通用强化。失去对应装备后，不继续推荐其强化；已获得的远征强化仍保留。全新武器通过站点装配进入构筑，不再新增一套战中英雄招募。

保存中断状态不等于结束远征，重进不能重复获得到站奖励、广告奖励或出站收益。

## 4. 第一批能力与转型目标

先验证三种主设备与一种功能设备，名称和分支为提案，不是新增已确认装备清单。

|设备|基础职责|第一阶段变化|成型目标|短板及转型补充|
|---|---|---|---|---|
|切割轮|清理贴车地面敌人|扩大有效覆盖或提高持续切割能力|能明显稳住一侧贴车压力|不能独自处理空中威胁，补电弧或无人机|
|电弧线圈|范围内对空与连锁清群|增加连锁覆盖，或提高集中打击能力|多目标清场或偏精英处理形成可辨差异|敌人分散或越过覆盖时补无人机／切割轮|
|无人机舱|离车机动补火力|增加作业单位，或提高集中作业能力|群体巡防或集中处理危险目标|不能包办所有覆盖，按敌情补近身清理|
|动力助推器|影响既有冲刺能力|本轮先只保留清楚的距离收益|出站与手动冲刺的距离变化可感知|占用装备容量，不额外增加能量币或第二冷却|

首轮每种主武器只验证少量清楚的分支与一个可感知的高阶结果；不同时铺开长技能树、模块升星、品质洗练和套装羁绊。

“成型”按能力表现定义，不以抽到特定稀有卡作为唯一标准。应存在次优但可继续推进的路线。前置条件必须直接显示，不设隐藏合成公式。

模块是否同名合成仍待定，不能把肉鸽强化自动等同于模块升阶。先做车厢既有合成与武器战中强化；站内武器合成广告须等对应正常合成规则成立后才设计。

## 5. 局外长期价值

初版集中在“车库研发”一个入口，不另外堆宠物、宝石、装备树。

- 蓝图扩展：解锁新的可玩设备，增加打法。不能只增加随机池噪声。
- 列车基础研发：有限的起手与基础能力提升，明确显示实际变化，不替代局内决策。
- 初始装配选择：从已解锁内容选择本次出发方向，避免每局完全依赖随机起手。

建议使用一种局外研发资源，正常结算可获得；初版不要求高级货币。主线推进提供新敌情与蓝图目标，失败也按明确已完成进度结算，广告仅在基础收益之外增加价值。

付费不应是体验新流派的唯一途径。长期目标先来自内容与路线，再用适量纵向研发支撑重复挑战；不靠普遍提高血量墙制造研发需求。

## 6. 免费、广告与付费路径

三者是同一玩家可以切换的行为，不是互斥身份。

|场景|免费正常路径|广告额外选择|海外付费候选|
|---|---|---|---|
|初始成长|教学、主线和正常结算|教学后可选择额外结算收益|明确范围的入门进度包，不独占核心蓝图|
|站点整备|真实免费补给；废料购买单独标价|匹配当前装备的补给或升级支持，与其他候选比较|后续测试指定广告奖励免观看权益，不提高点位次数上限|
|战败|正常结算并调整下一次装配|看广告继续本次挑战，规则另定|首轮不新增无限付费复活|
|长期研发|游玩获得研发资源|明确目标的额外资源|有限进度加速；是否成立取决于留存和付费测试|
|外观|主线或活动内容|按内容价值决定是否适用|外观直购；不是早期收入假设的唯一支柱|

站点示例（演示比较关系，不是最终商店规则）：免费补一个可用的近身设备、用废料买电弧补对空、看广告获得当前车厢合成支持。三者解决不同问题；必须显示容量与成本，不能把免费项做成无效陪衬。是否互斥、是否组合购买另定，领取支持不自动合成。

复活与正常结算不是等值奖励比较：它们分别保留本次挑战或结束并保留正常所得。界面清楚说明差别，不暗示正常结算会没收已得资源。

教学先用免费内容完成“获取—安装—看到战斗效果—理解容量取舍”，之后才呈现广告候选。不得强制看广告完成教学，不在战斗过程中强制插屏。

“去广告”商品需明确是取消强制广告还是免观看领取指定激励奖励。只有自愿激励广告时，不出售含糊的“去广告”；权益范围、期限和次数必须清楚。

## 7. 版本规划与进入条件

|版本|交付重点|暂不做|进入下一阶段前验证|
|---|---|---|---|
|V0共同底座|连续远征、跨站强化、首批武器、站内容量取舍、完整结算|真实支付、复杂局外体系|不看广告能完成核心体验；有成型反馈和替代路线|
|V1国内IAA验证|免费教学、最小研发、少量站点广告比较与结算点位，复活按规则验证|广告专币、容量广告解锁、强制广告教学|拒绝广告仍可玩；奖励实际有用；留存与策略选择未被挤压|
|V1.1海外混合试验|相同核心玩法、当地适配、少量明确权益和进度商品|大型商城、抽卡、赛季叠加|净增收入而非仅替代广告收入；基础用户体验可接受|
|V2内容与运营|更多设备、敌情、章节；有需求再做挑战或通行证|为上线而堆养成入口|已有持续游玩与内容消耗证据，新增系统有明确职责|

海外渠道、平台与本地化可以提前准备；商品只预留清楚的奖励与权益边界，不提前建设大型商业基础设施。国内数据不能直接代表海外，需要独立测试。

共用核心规则、内容结构及默认平衡；分渠道配置广告可用性、奖励额度、商品和权益。不得出现同一文案在两市场具有隐蔽不同效果。无广告填充时必须有可走的正常路径。

## 8. 验证框架

先看是否形成可理解、可重复的体验，再看收入。

- 战斗：贴车积压、阶段受伤、武器贡献、冲刺使用时机、强化后的表现变化。
- 构筑：每站调整是否有意义、成型发生在哪段、未抽到目标时如何转型、容量取舍原因。
- 教学：能否不用广告完成基础流程、是否知道升级作用与代价。
- IAA：免费与广告选项选择分布、奖励使用率、升级兑现、拒绝广告后继续游戏、观看后流失。
- 混合：付费与广告总收入、留存、重复购买与进度消耗；不要只看内购收入增加。

免费／广告／付费玩家天然存在行为差异，不能直接把分组胜率差当作商业方案的因果效果；有条件时按一致起点和可控实验比较。具体指标门槛待测试方案，不编造行业达标线。

## 9. 决策顺序与当前交付边界

建议下一轮先细化“共同远征成长规则”，确定跨站保留、武器类型强化、起手选择及结束结算；之后做首批武器分支，再做站点候选与教学，最后排商业奖励数值。

优先需确认的产品提案：

1. 一次远征跨多个站点，肉鸽强化全程保留，结算才清除。
2. 强化绑定本次远征武器类型，同类模块共享；新模块通过站点获取。
3. 局外先做蓝图、有限研发和初始装配，不增加独立碎片品质体系。
