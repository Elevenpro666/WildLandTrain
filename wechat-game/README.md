# 荒野列车 · 微信小游戏可检查版

这是独立于 `station-prototype` 的 Canvas 验证工程，复用同一套列车、战斗、远征、经济和 Boss 规则；不是把网页放进微信壳。原浏览器原型未覆盖。

## 直接检查

- 浏览器同画面预览：打开 `http://127.0.0.1:4190/dev-preview.html`。此地址的本地服务由当前任务启动；以后重开可在本目录运行 `python -m http.server 4190 --bind 127.0.0.1`。
- 微信开发者工具：打开本目录 `E:/GameFactory/荒野列车/wechat-game`，项目类型为“小游戏”。已填测试 AppID `touristappid`，正式真机预览需换成项目实际 AppID 并登录相应账号。
- 改源码后在本目录运行 `npm install`、`npm run build`。开发者工具读取生成的 `game.js` 与 `assets/`。原图不被覆盖，构建时自动生成约 102 KB 的九张透明运行图。

## 建议检查路线

1. 整备：选车厢、买车与装备；点已装图标进周转，点周转图标装回，角上的“售”需二次确认；选车后点“合成车厢”，再点同级另一节并确认。待编车厢可在轨道下方选择。
2. 出站：屏幕向上战斗；击败敌人获得废料和经验，弹出三选一强化。右下冲刺充满可手动释放；Boss 出场后不可冲刺。
3. 到站：列车在整备页的轨道中从左驶向右，停稳后可继续整备。第三段击败持铁者后进入结算，再点“重新出发”。

## 验证与边界

- `npm run check`：无画面规则会话测试；`node verify-canvas.mjs`：需本地 4190 服务，执行真实 Canvas 点击并保存 `output/canvas-flow/` 截图。
- 已检查 390×844 和 320×568 的浏览器同画面预览，三段胜利流程与触控操作通过；微信开发者工具已能打开工程，但**尚无微信模拟器逐帧截图或手机真机运行、性能、玩家理解的验收证据**。
- 本版以验证战斗闭环为目标，仍缺正式存档、广告、支付、音效、完整拖拽与全部装备处置 UI。数值仍为原型测试值，不能作为上线版本。
